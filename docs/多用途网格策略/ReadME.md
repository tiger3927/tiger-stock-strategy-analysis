# 多用途网格策略（方案 ReadME · v2）

> **定位**：本文档是方案记录与意图规范。它把"一笔持仓里同时追多个目标"的旧范式，重构为"**一套策略、一仓一意图、三种意图可切换**"的范式。
>
> **触发背景**：[复盘记录/2026-09-19/技能改进A.md](../../复盘记录/2026-09-19/技能改进A.md) —— GE 案例实证：AI 画带漂移、窄带上跳、意图与扳机脱节，根因是**一笔持仓被迫同时承载多种互相冲突的目标**（既要等回踩、又要抓突破、又要收波动），AI 每轮都在给闸门换位置。
>
> **策略依赖**：方案所需的全部能力（止损幅度自由设定、网格触发模式可选等）**已在策略中就绪**；本文只描述用法与规范，不引用旧策略文档——本目录所有文档自成体系。

## 一、深刻反思：旧范式的病根

### 1.1 病根不在引擎，在"一笔持仓多目标"

| 病灶（技能改进A） | 旧范式下的表现 | 本方案的釜底抽薪 |
|:--|:--|:--|
| 带的锚从结构位漂移到现价下方1% | 同一笔持仓同时有"等回踩"和"别踏空"两个目标，突破时刻两者打架，AI 折中出贴价带 | **一个持仓只有一个意图**（写进主题+合同），等回踩就绝不追高——"别踏空"这个目标在本次持仓里根本不存在 |
| "等待回调"没有定义成深度 | 嘴上禁令与手上扳机脱节 | 反转/抄底意图天生"只等不追"（首仓区间上限+择机）；追势交给趋势意图——**禁令在意图参数里天然成立** |
| 窄带+每轮重画+突破可重锚 = 机械上移 | 三机制叠加的必然输出 | 反转意图的带由"主题+合同"锚定大级别结构位，AI 无重锚授权；要换结构位必须等仓位=0 后切换意图 |
| 无前轮平仓价记忆 | 策略状态缺锚 | 由合同文本（备注）显式记入"上一手为什么平"，不依赖策略记忆 |

### 1.2 逆向思维：不是"把策略变聪明"，而是"把策略变笨"

- **旧思路**：一个策略 + 越来越多参数 + 越来越长文档，让 AI 在每个阶段做对所有事 → 认知负荷爆炸，必然出错。
- **新思路**：**空仓时**选定唯一人格（长期主题 + 配套参数），**持仓期内只服务这一个意图**。AI 每轮只需回答一个问题："这一轮，对这唯一意图而言，该做什么？"
- **时间是防火墙**：三种意图不同时并存，而是按行情阶段**依次轮换**（空仓时自由切换；持仓期仅在"持仓兼容 + 行情重大变化"时整套切换，无重大变化不得换）。一个意图的失败不会污染下一个意图——因为切换必须显式重写合同（空仓时由宏观层同步重写核心思路声明）、换参数组合并留痕。

### 1.3 能力边界（v2 已核实）

- **策略已支持**：三种意图参数组合（空仓可切；持仓期有条件切换，§4.2 流程 B）、主题三明治、六阶段生命周期、探针按意图启用、首仓区间/禁止追高、ATR 止损止盈、移动止盈、冷却与去重、参数变更与留痕。
- **策略已内置**：止损幅度自由设定（与网格公式解耦，公式值仅作参考）、网格触发模式可选（CCI / 纯价格，`enable_cci_chance_only`）。
- **策略天然做不到、必须接受**：固定止损不可关闭（关了就不能开仓）；每格资金等份；空仓时"禁止追高"不生效（此时唯一闸门是首仓价格区间的上限）；**AI 报告不落地任何参数**（参数只能由人工 / MCP 设置）。

## 二、核心思想：一码多用、一仓一意图

```
                         ┌─ 趋势     趋势跟随   一把仓吃波段，不用网格（首仓占比→1.0）
  一套策略 · 三种意图      ├─ 反转     反向接货   抓V反1~3格大间距 / 阶段抄底4~6格，错了立刻砍
                         └─ 波动收波 网格收波   8~10格小间距收区间差价，单边打穿即认输
```

**四条铁律：**

1. **同一时间只承载一个意图**。意图写在 `openclaw_main_approach`（长期主题）里，AI 只读。持仓期内不允许出现第二目标；要做第二件事 = **等本次持仓结束（仓位=0）后切换意图**。
2. **一个持仓只有一个意图**。持仓行为与备注（`openclaw_user_remark`）背离时，只有两条出路：**平仓** 或 **改换意图**（重写备注 + 换参数组合），不允许"既不认账也不处理"地漂着。
3. **人格（意图）的绑定与更换由人决定**：
   - **空仓观察 / 等待首仓**（pos=0）：可随行情自由更换意图——动作 = **人工 / 外部宏观分析智能体**经 MCP 重写长期主题（`cta_strategy_set_main_approach`；**本模块的策略 AI 与操作不修改主题**，只按新主题核对参数）+ 同步换参数组合（§三是三份现成组合）；
   - **持仓期**（pos≠0）：原则上锁定；仅当**持仓价/量与目标意图兼容**（00-Index §1.3 三条件）且**行情重大变化**时可整套切换（意图须连贯，无重大变化不得换、不得高频换），否则先清仓；
   - **等待首仓起必须有意图**（长期主题 + 配套参数组合，缺一不可）；
   - AI 无权自行换意图，也无权扩展意图边界，只能在当前意图边界内做决策。
4. **方向只在仓位=0 时翻转**。参数是双向共用的（同一参数按持仓符号反向解释），所以：**持仓期内不做反向**；要由多转空，先走清仓（利润收割期"立即清仓"或风险退出期），**清仓后**再切换意图与方向。反向开仓不受"同向冷却"拦截，但必须在主题/合同里显式改向并留痕。

## 三、意图原型卡（三种意图）

> 参数名：AI JSON 用中文名，MCP/建实例用英文名。资金公式：首仓量 = 总资金 × `建议首仓占比`；每格量 = 总资金 × (1−首仓占比) ÷ `网格数量`。
> **两个前提**：①**固定止损不可关闭**——所有卡片的"是否允许止损"恒为 true；②**止损幅度与网格解耦**（2026-09-19 起不再强制 ±15%，`stop_loss_radio` 仅受 0.01~1.0 钳制）：卡片"目标止损"列是自由取值，"间距×数量×0.6"只用于日志留痕——"早于网格深度"=快砍意图，"晚于网格深度"=兜底意图。
> **杀手锏**：`建议首仓占比 = 1.0` 时每格量 = 0，网格物理失效——"不用网格"用占比表达即可（开关也建议关，双保险）。
> **切换方式**：三种意图共用一份参数表；仓位=0 时按 §四 流程 A 改长期主题 + 套用本表参数组合；持仓切换走 §四 流程 B（兼容三条件 + 重大变化，子型切换同规则）。

### 3.1 趋势意图（趋势跟随）—— 一把仓吃一段

| 维度 | 配置 | 说明 |
|:--|:--|:--|
| 长期主题 | `"趋势跟随：突破回踩确认后一笔进场，跌破结构即空仓，不摊低成本，不做逆势抄底"` | 意图宣言，AI 只读 |
| 建仓 | `建议首仓占比=0.8~1.0`；`网格数量=0`；两个加仓开关全 false（亏损加仓/盈利加仓，红线：不摊低成本）；`是否允许网格主动开仓=true` | 每格量=0、网格物理失效；`网格数量=0` 明确表示"这不是网格"；主动开仓≠加仓——它是首仓入口（CCI+区间埋伏） |
| 止损 | **固定止损必须开 = 0.02~0.05（默认 0.03）**：超过 = 趋势形态预测错误，立砍（形态失效线） | 不再需要 ATR 止损/移动止盈：ATR 兜底永不会先触发；移动止盈窄了未到目标就洗出、宽了永不触发——盈亏比由固定止盈执行 |
| 盈亏比 | **预期 ≥3:1（至 5:1）**：目标 = 3~5× 止损距离（默认 9~15%）；合同 ③⑥ 按此写 | 超止损线不辩护"也许会回来"——形态假设已废，直接执行止损 |
| 入场纪律 | `是否限制首仓价格区间=true` + 区间锚定**突破确认后的回踩位**（上限=回踩区上沿） | **空仓时唯一有效的不追高闸门是首仓区间上限**（空仓时"禁止追高"检查不生效） |
| 等待首仓轮必做 | `是否允许止盈`=true + `止盈幅度` 写到 **0.09~0.15**（=3~5× 止损，盈亏比 3:1~5:1，到达即离场） | 等待首仓阶段基线=止盈开，开仓前必须写好（开关关则幅度不生效） |
| 触发模式 | 网格加/减无关（网格关闭）；**主动开仓=true**，恒须 CCI 同向（埋伏=价格进首仓区间 + CCI 自动开） | — |
| 探针 | `enable_ema_cross_probe=true`（按品种调快慢线）+ `enable_atr_probe=true` | 交叉触发重评，天然匹配趋势 |
| 节奏 | `openclaw_main_interval` 拉长（数小时级） | 防噪声扰动 |
| 怕什么 | 震荡市反复打脸 / 做反趋势 / 买到趋势末尾 / 持仓期出现风险事件 → 前三者交给 3% 形态失效线（只在"趋势枚举=看涨/看跌 且置信≥0.75"时建仓，横盘保持空仓）；**风险事件（财报/宏观/黑天鹅）立即 `操作=立即` 清仓，不等止损** | |

### 3.2 反转意图（反向接货）—— 两种入场锚定

> 同一意图族、同一套参数表，按"接的是拐点还是深跌"分两个子型：**抓V反**买"拐点已现"，**阶段抄底**买"跌得深"。两者参数差异很大，**子型切换按 00-Index §1.3 同规则执行**（A→B 通常不兼容——A 仓位更重，一般须先清仓；B→A 需成本在结构位带内）。

| 维度 | 子型 A：抓V反（1~3 格重仓接刀） | 子型 B：阶段抄底（4~6 格等修复） | 说明 |
|:--|:--|:--|:--|
| 长期主题 | `"抓V型反转：仅在大级别成交密集区+超卖背离时接刀，错了立刻砍，不做趋势跟随"` | `"阶段抄底：深度回踩至支撑区接多，等均值修复到中轴离场，不追新高，不做趋势跟随"` | 区别：A 买"拐点已现"，B 买"跌得深" |
| 建仓 | `建议首仓占比=0.5~0.7`、`网格数量=1~3`、`网格间距=0.05~0.10`、`网格止盈=0.04~0.08` | `建议首仓占比=0.2~0.3`、`网格数量=4~6`、`网格间距=0.03~0.05`、`网格止盈=0.03~0.05` | 每格量：A≈总资金 15~25%（重仓接刀）、B≈15~19%；`网格数量` 同时限制最多加仓次数 |
| 止损 | 0.06~0.12（已解耦，自由设定） | 0.09~0.15（已解耦，自由设定） | 生命线，快速证伪 |
| 加仓 | `是否允许亏损时网格加仓=true`（弹药天然只有 1~3 格） | 同左（弹药 4~6 格） | 反转是靠"摊一次成本"，不是摊十次 |
| 触发模式 | `仅允许CCI触发加减仓=true`（默认） | 同左 | 反转靠择时，不宜纯价格网格 |
| 入场纪律 | `首仓价格区间` 锚定**已确认的大级别结构位**（上限=结构位上方 0.5~1%）；`操作=择机` + `是否允许网格主动开仓=true`（CCI 到价自动开） | `首仓价格区间` 锚定一级/二级支撑（上限=支撑区上沿，回踩深度 ≥1×ATR 才许画） | 只等不追：靠首仓区间上限 + 择机（技能改进A 的 R1/R2 落在这里） |
| 风控补充 | — | `是否允许止损=true` + `是否允许移动止盈=true`（启动 0.04 / 回撤 0.02） | 修复段用移动止盈锁定 |
| 探针 | `enable_rsi_div_probe=true` + `enable_rsi_probe=true`（超卖 20~25） | `enable_rsi_probe=true`（超卖 25~30，比 A 宽松）+ `enable_atr_probe=true` | 背离+超卖=拐点；超卖+ATR=深度 |
| 节奏 | `openclaw_main_interval` 短（15~30min 级）；冷却期建实例时设短或 0（人工设置） | 中（30~60min 级） | 反转窗口稍纵即逝 |
| 怕什么 | 中枢下移、反转变新趋势 → 触止损无条件走风险退出 | "偏离"变"新趋势" → 分位 <0.2 证据不足时降档（首仓占比 0.1~0.15） | 共同失败模式：接刀接到趋势 |

### 3.3 波动收波意图（网格收波）—— 8~10 格收区间

| 维度 | 配置 | 说明 |
|:--|:--|:--|
| 长期主题 | `"网格收波：区间震荡来回赚差价，不猜方向，单边打穿即止损认输，不追趋势"` | |
| 建仓 | `建议首仓占比=0.15~0.25`、`网格数量=8~10`（**方案上限 10**）、`网格间距=0.02~0.03`（币 0.03~0.05）、`网格止盈=0.015~0.025` | 每格量 ≈7.5~10.6%；`网格数量` 即最多加仓次数 |
| 止损 | **≈0.6×间距×数量**（默认 0.15，0.10~0.18；币宽区间到 0.25+），已解耦自由设定 | 止损锚定**区间下沿**：满格时均价≈区间中点，止损须比半区间宽+1 格，线落在区间底之下才不算"区间内被砍"；部分加仓时必然早于区间底触发=早砍少亏（设计如此） |
| 加/减仓 | `是否允许亏损时网格加仓=true` + `是否允许网格减仓=true`（对开成闭环） | |
| 触发模式 | 二选一（**建实例时人工/MCP 定**）：`仅允许CCI触发加减仓=true`（稳、成交少）或 `=false`（纯价格网格、成交密、耗弹药快）。若选 `false`，必须同时满足 §6.4 的四条约束（共用节流已内置；**不要卖基础底仓**；并可酌情收紧 `网格数量`） | |
| 入场纪律 | `首仓价格区间` 锚定区间中枢或下沿（上限=区间上沿） | |
| 方向纪律 | `base_direction` 跟随大环境：**偏多环境只做多网格、偏空环境只做空网格**；做反（牛市做空网格/熊市做多网格）= 单边打穿时**逐格堆损**，最大毁损模式 | "不猜方向"= 不猜区间内短期；持仓符号不可随便选 |

## 四、意图切换与资金

### 4.1 资金是宏观 AI 的事

`start_asset` 由**宏观调仓 AI / 人工经 MCP** 在建实例时一次性设定，此后是固定数。**策略 AI 只读、不关心、不校验、不干预**；`Σ start_asset ≤ 账户可用资金` 由宏观层负责。注意：`start_asset = 0` 的实例首仓量为 0，**开不出仓**（实测存在此类实例），建实例时必须写非 0。
**切换意图不改 `start_asset`**——它是这个品种的固定本金，与当前是哪个人格无关。

### 4.2 切换流程（两条路径）

**A. 空仓切换（默认路径，仓位=0，空仓观察/等待首仓）**

```
① 确认仓位=0
② 判定行情类型：趋势枚举 / 区间震荡 / 结构位反抽
③ 选定意图（§三 三选一），确定子型（抓V反 或 阶段抄底）
④ 确认长期主题已由人工/外部宏观分析智能体更新（**本模块不改主题**）；未更新则中止切换并上报
⑤ 按 §三 换齐参数组合（首仓占比 / 网格数量·间距·止盈 / 止损 / 探针 / 主动开仓 / 触发模式）
⑥ 从"等待首仓"起建仓；建仓后意图锁定，直到清仓
```

**B. 持仓切换（有条件例外，见 00-Index §1.3）**：同时满足才执行。**改的是合同，不是核心思路**：① 前置——目标意图在核心思路边界内（越界 → 上报宏观层调整，不得自行切）；② 本模块**重写合同**（写明上一意图为何结束、本轮为何换）；③ 经 MCP 换齐参数组合并读回验证；核心思路不动：

1. 兼容三条件：方向一致 / 当前持仓占比 ≤ 目标意图首仓占比上限 / 成本在目标意图入场纪律内；
2. 行情重大变化且连续 2 轮确认；
3. 不满足任何一条 → 走利润收割期/风险退出期清仓，回到路径 A。

**不建议频繁切换**：切换有成本（冷却期、探针窗口、AI 每轮重申合同的负担），一天内来回换意图等于没有意图。

### 4.3 三条切换纪律

1. **空仓切换是默认路径，持仓切换是有条件例外**（00-Index §1.3）：持仓价/量与目标意图**兼容**（方向一致 / 仓位占比≤目标首仓占比上限 / 成本在目标入场纪律内）且**行情重大变化（连续 2 轮确认）**才许持仓期换（意图须连贯：无重大变化不得换、不得高频换）；不满足 = 先清仓再切。
2. **切换必须留痕**：核对主题已由宏观层更新 + 写参数修改理由 + 在合同里说明"上一手为何结束、本轮为何换意图"。**有痕为改、无痕为漂**（§5.3）。
3. **意图边界由人写定**：AI 只能在主题划定的边界内决策；什么时候用哪个人格（今天趋势、明天收波）是人的资源分配，不是 AI 的自主决策。

### 4.4 阶段状态机照旧

实例内部仍使用六阶段生命周期（空仓观察→等待首仓→首仓建立中→网格管理期→利润收割期→风险退出期）——**多阶段布局不变，变的只是当前这一手用哪个人格**。阶段×参数权限矩阵与输出 JSON 协议分别由 `03-生命周期与阶段权限.md`、`06-输入输出协议.md` 承载（见 §七）。

## 五、主题三明治（意图传递与治理）

### 5.1 三层文本（**允许结构化文本，不必 JSON**）

| 层 | 参数 | 角色 | 谁写 | 生命周期 |
|:--|:--|:--|:--|:--|
| 宪法 | `openclaw_main_approach`（策略核心思路） | **本实例是谁、只做什么、绝不做** | **人工 / 外部宏观分析智能体**（经 MCP）；本模块只读不改 | 长期有效；**空仓观察可不设、等待首仓起必须有**；仓位=0（空仓观察/等待首仓）可随行情更换，建仓后（首仓建立中→风险退出期）锁定（铁律 §二-3） |
| 合同 | `openclaw_user_remark`（备注） | **本手意图**（方向/依据/目标位/失效价/时限）+ **考核条款**（成功/失败判据、到期处置）；开仓前写好，每轮自检与复盘以它为唯一标准 | MCP 或 AI（AI 仅非空时写入） | 持续保留到被覆盖；**清仓后不会自动清除**，换意图时须显式重写或清空 |
| 电报 | `openclaw_notice`（通知） | 短期修正指令/事件警告 | MCP `cta_strategy_send_notice` | 短期，新覆盖旧 |

**推荐行文（结构化中文，不需要 JSON，关键是每条都在、可被复核）：**

```
宪法：本实例=反转意图（抓V反）｜只在大级别结构位抓V反｜绝不追趋势、绝不摊低成本、绝不在震荡上沿接货
合同：方向=多｜依据=一级支撑205（近3月3次触碰未破）+日线RSI底背离｜目标位=218(二级压力)｜
      失效价=198（跌破即结构破坏，无条件止损）｜时限=5个交易日｜
      前一手=8/3 于364.22止损离场，本轮买入上限≤364.22×1.02｜
      考核：成功=5根日线K线内脱离成本≥1×ATR；失败=跌破198 或 到期未脱离成本 → 无条件风险退出
电报：8/20 CPI公布前禁止开新仓
```

### 5.2 AI 每轮的一致性自检（系统不做校验，靠 AI 自检）

写入 AI 输出契约（提示词与 06 号文档），每轮必做三问：

1. **本轮决策与"宪法+合同"一致吗？** 若不一致 → 要么改回一致，要么走 §5.3 的"改换意图"（不许沉默偏离）。
2. **合同的失效价/目标位还有效吗？** 形态已破坏 → 失效价即刻生效（止损/风险退出），或显式改换意图。
3. **我的参数改动，是否等于在偷偷改人格？** 改动人格相关参数（首仓占比、网格数量/间距、止损、触发模式）必须在"参数修改理由"里声明是"人格内调整"还是"换人格（须人工/MCP 确认）"。

> 建议在 AI JSON 模板增加一个**冗余字段**（系统不解析、零成本，供复盘）：
> `"意图一致性": "与合同一致 | 已按流程改换意图（原因…）| 发现偏离，本轮执行处置"`

### 5.3 意图违背的处置（只有两条路：平仓 或 改意图）

**判定取数**：`cta_strategy_get_status`（持仓/参数 vs 合同方向与规模）、`cta_strategy_get_all_reason`（参数历史 + 逐参数理由）、`cta_strategy_get_trades`（成交流水时序 vs 合同进入区）。

```
意图违背？
├── 方向性违背（合同做多、却做空；合同等回踩、却追高成交）
│     → 平仓：利润收割期"立即清仓" / 风险退出期清仓；同向有冷却期（默认48h，人工设置）
├── 幅度性偏离（仓位超合同、网格参数漂移但方向对）
│     → 改意图 或 收敛参数，二选一，必须写明
├── 意图过时（结构已变，原目标不再合理）
│     → 改换意图：重写合同 + 换参数组合 + 在理由中写明废止原因（合法路径，前提是"改"不是"漂"）
└── 无违背 → 执行中每轮**追加**合同 ⑧ 现状（追加写入；无新变化可保持现值，不重复抄写 ①~⑦）
```

**"改"与"漂"的区分**：改意图有留痕（备注重写 + 参数修改理由 + 未采纳注入）；漂移无留痕（什么都不写，行为却变了）。**复盘时：有痕为改、无痕为漂，漂即处置。**

### 6.2 人工层固定参数清单（AI 不许改）

`init_load_days`、`use_1m_5m_15m_30m_60m`、`cci_martin_period`、`martin_k_time`、`target_delay_minute_max`、`volume_change_with_v`、`us_stock_trading_hours_only`、`loss_close_need_manual`、`close_cooldown_hours`、`x_script`/`y_script`/`x_window_count`/`y_window_count`、`enable_publish_status_redis`、`trade_radio`/`trade_fee`/`volume_min_unit`/`order_price_add`。

### 6.3 策略硬约束（意图必须服从）

| 约束 | 事实 | 应对 |
|:--|:--|:--|
| 固定止损不可关 | 止损未开启时禁止开新仓 | 所有卡片止损恒开（§三） |
| 空仓时"禁止追高"不生效 | 该检查要求 `pos ≠ 0` | **空仓唯一闸门 = 首仓价格区间上限**；禁止追高用于持仓后加仓防线 |
| 等待首仓阶段的阶段基线 | 止盈/移动止盈/止损=开 | 该轮就把 `止盈幅度` 写到 0.09~0.15（趋势意图 = 3~5× 止损，盈亏比 3:1~5:1） |
| 首仓建立中的阶段基线 | 只开止损、关止盈/移动止盈（**例外：趋势=止盈全程保持开**） | 该阶段只靠止损保护（趋势止损=形态失效线；反转/波动=ATR 兜底） |
| 网格管理期的阶段基线 | 不卖基础底仓、不主动下单（不下发立即单；**网格加/减仓照常按参数执行**） | 想减仓走"网格减仓"；想清仓走利润收割/风险退出期 |
| 风险退出期的阶段基线 | 卖底仓 + 网格减仓全开 | 进该阶段即出货模式，别再开加仓开关 |
| 每格资金等份 | `(1−首仓占比)/网格数量`；`网格数量` 同时是最大加仓次数 | 意图只能用这两个旋钮表达仓位轻重（§0-4） |
| `enable_openclaw_analysis` 默认关 | 不显式打开 = 纯机械网格，无任何 AI | 建实例必须显式打开 |
| V 形/窄带无重锚授权 | 首仓区间只在"等待首仓/首仓建立中"可开 | 反转/抄底意图每轮重申区间；AI 无重锚许可（技能改进A R1/R4） |

### 6.4 价格网格模式（`enable_cci_chance_only=false`）使用约束

价格模式把"CCI 择时"换成"到价即动"，成交密度与弹药消耗都远高于 CCI 模式。策略已内置两道保护，另需遵守两条人工约束：

| 项 | 内容 | 谁保证 |
|:--|:--|:--|
| 共用动作节流 | 加仓与减仓共用同一 `(成交等待分钟数+1)` 分钟节流窗口；一次网格动作后窗口内不再有第二个动作（修掉"综合浮盈达标时逐根 K 线连续减仓"）。**两种模式统一**（方案B，2026-09-20）——CCI 模式下减仓节奏也由"信号窗口内可逐根 K 线连减"变为"每 (n+1) 分钟一次" | 策略已内置 |
| 同根 K 线互斥 | 同一根 K 线先做出减仓决策后，不再做加仓决策（CCI 模式下由 direction 符号天然互斥） | 策略已内置 |
| **不卖基础底仓** | `是否允许卖出基础底仓=false`：逐格减仓会随 `poschange` 消耗而自限，而底仓减仓是"按比例重复执行"的通道，价格模式下风险最高 | 人工/MCP 建实例时设定 |
| **只用于震荡收波型意图** | 只给波动收波意图开价格模式；并据弹药预算收紧 `网格数量`、配好 ATR 止损 | 人工/MCP 建实例时设定 |

> 另：价格模式成交备注写"网格价格触发"，CCI 模式写"网格CCI触发"（**主动开仓恒为 CCI 文案**，因为它两种模式下都必须 CCI 同向）——复盘可直接从备注区分触发来源。
> 风险退出期的**阶段基线**是卖底仓+网格减仓全开：若实例是价格模式且处于盈利，退出会表现为"每 (n+1) 分钟一笔的分批出货"；需要整仓立即退出时，由人工/MCP 直接下目标仓清仓（不走网格减仓）。

## 八、一句话总结

> **旧范式让一个策略在每一轮都做对所有的事——它做不到；新范式让一个持仓只有一个意图：空仓时选定人格（趋势 / 反转 / 波动收波），持仓期不漂移，由人工/宏观智能体把"只做什么、绝不做什么"写进长期主题，把当前这手的方向与失效价连同考核条款写进合同，把短期禁令写成电报。AI 每轮先对三明治自检，一致就执行、不一致就走"平仓或改意图"两条路——没有第三条"漂着"的路。主题与参数分三层：人工/宏观智能体定主题与阀门、MCP 改基线参数、AI 只出报告（结论字段落地，参数建议仅留痕）。**
