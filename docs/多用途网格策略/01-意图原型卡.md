## 1 选意图（主锚：`接下来的行情形态` + `预测置信度`）

> 判"**将要发生**"，不判"已经发生"：形态判断一律用 §1.3 的三类可核对量表达；`趋势枚举`（看涨/看跌/…）只是 AI 报告里的表达字段。
> **意图列 ↔ §2 卡片一一对应**：趋势→§2.1｜反转→§2.2（A/B 由下面两行区分，判据与其剧本前置一致）｜波动收波→§2.3。"不建仓 / 空仓观察"是**状态**，不选卡、不切意图。原理（一仓一意图、换意图只在仓位=0）见 [`ReadME.md`](ReadME.md) §二、§三。

| 接下来的行情形态（前瞻判断） | 置信度 | 证据（取自 §1.3，≥2 项） | 意图 → 对应卡 |
|:--|:--:|:--|:--|
| **趋势将启动**（压缩态）或**将延续**（回踩确认中） | **≥0.75** | 压缩态 ≥3 项；或回踩三条件全中；方向与关键结构位一致 | **趋势** → §2.1 |
| 方向对但**位置不对**（尚未到触发线，或已远离结构位） | 0.60~0.75 | — | 不建仓（状态）：等待首仓 + 操作=禁止，等回踩到位再定 |
| **趋势将反转**——拐点将现（衰竭/背离，逼近 2~3 级结构位） | ≥0.60 | 背离 **或** 触及高阶结构位（必有其一）+ ≥1 项辅助（NATR 突增 / 长影线） | **反转·A 抓V反** → §2.2 子型 A |
| **深跌将到位**——回踩进行中（距 1~2 级支撑 ≤0.5×NATR、缩量阴跌） | ≥0.60 | 预计深度 ≥1×ATR、分位 0.2~0.4、NATR 不极端 | **反转·B 阶段抄底** → §2.2 子型 B |
| **区间将延续**（无方向） | ≥0.60 | 往返 ≥3 次、宽 2~5×NATR、EMA 缠绕、无单边结构破坏 | **波动收波** → §2.3 |
| 证据不足 | **<0.6** | — | 空仓观察（状态）：不切意图 |

**否决项**：①NATR 近 3 月分位 >90% → 不选收波；②24h 分位 >0.85 或 <0.15 → 不新建仓；③同一判定**连续 2 轮**成立才切换（防一根 K 线换意图）。

### 1.2 判定前的数据获取（每轮必做）

| 数据 | 来源 | 用途 |
|:--|:--|:--|
| 策略状态 / 持仓 / 三明治 / 冷却 | vnpy_mcp `cta_strategy_get_status` | 当前参数实际值、阶段、冷却期 |
| 参数修改历史 / 理由 / 成交流水 | vnpy_mcp `cta_strategy_get_all_reason`、`cta_strategy_get_trades` | 意图一致性核对、"前一手"复盘 |
| **盘面 K 线（主数据）** | vnpy_mcp `get_history_bars(vt_symbol, interval, start, end)` + `get_tick(vt_symbol)` | **形态识别唯一盘面来源**（与下单同源）：算 §1.3 全部指标（NATR 分位、箱体、EMA 间距、RSI 背离、推进幅度、量能） |
| 联网行情（补充） | `scripts/get_market_data.py --market <市场> --tickers <本品种>`；长历史用其 `get_history_dataframe(ticker, period)` | 价格/涨跌幅/均线/52 周分位；仅当品种不在 vnpy、或需要 1 年长历史时用 |
| 板块与大盘 | `--batch us-sectors`（板块 ETF）、`us-major-indices`、`us-all`；加密用 `crypto-all`（大盘锚/L1/DeFi/Meme/基础设施） | 板块强弱与轮动背景 |
| 事件面 | `--fetch-url calendar`（经济日历）、`--fetch-url product-all-info --ticker <本品种>`（新闻+评级） | 禁开仓窗口、催化剂 |

### 1.3 三类可核对量（主周期）

| 即将发生 | 指标 | 门槛 🎚 |
|:--|:--|:--|
| 趋势将启动 | ①NATR 近 60 根分位 <30% ②箱体宽/价 1.5~3×NATR ③距箱体边界 ≤0.5×NATR ④EMA 快慢间距/价 <0.5×NATR | **≥3 项**=压缩态 |
| 趋势将反转 | ①RSI 背离（价新高 ≥0.5×ATR 而 RSI 高点下移 ≥3）②推进幅度递减（近 3 根实体均值 < 前 3 根 70%）③触及 2~3 级结构位（≤0.3×NATR）④NATR 突增 | ①**或**③必有 |
| 趋势将延续 | ①回撤 ≤0.5×突破幅度 ②回撤期波动/量能 < 突破期 70% ③回踩不破突破位 | 三条全中 |

**领先 / 滞后**：压缩、背离、衰竭、回踩=**领先**（可作开仓依据）；EMA 交叉、突破当日、大阳/大阴线=**滞后**（只作确认）。

### 1.4 提前量机制（谁来唤醒意图识别）

**① 唤起来源：共四个，前两个在程序内自动运行，后两个在程序外**

| 唤起来源 | 机制 | 前置条件 | 特点 / 用途 |
|:--|:--|:--|:--|
| 1. 程序内**指标探针** | 主周期 K 线收盘计算四类信号，触发即发起一次 AI 分析：RSI 顶底**背离**、ATR 波动率**突变**（领先）；RSI 极端区（同步）；EMA **金叉死叉**（滞后） | 对应 `enable_*_probe=true` | **领先信号叫醒**是主要提前量来源；探针只负责"叫醒"，判定仍走 §2.0 四步，不直接开仓 |
| 2. 程序内**定时 AI 分析** | 每 `openclaw_main_interval` 分钟自动调用一次 | `启用AI策略分析`=true 且周期 >0（≤0=关闭） | 兜底轮询；**必须 ≤ 主周期分钟数**——否则形态在两次分析之间走完，永远慢一拍（平均滞后 ≈ 定时周期的一半） |
| 3. **人工**触发 | UI/命令手动发起分析 | — | **不受总开关限制**；用于关键时点（逼近触发线、重大事件落地后） |
| 4. **外部智能体**经 MCP 触发 | MCP 侧发起分析（与人工同通道） | — | **不受总开关限制**；盯盘智能体发现形态即可即时唤醒，是"接近实时"的主要路径 |

> 多个来源同时唤醒 → **串行排队**（先到先分析，不并发）。提前量 = 探针（领先）+ 定时（兜底）+ 人工/MCP（实时）三者的组合；只靠定时一种时，必然经常赶尾声。

**② 唤醒之后，把提前量变成仓位（三个手段）**

| 手段 | 用法 |
|:--|:--|
| `是否限制首仓价格区间` + `操作=择机` + `是否允许网格主动开仓=true` | **埋伏**：形态未完成就把区间写好，价格自己走到即开仓——这一步不依赖"被叫醒" |
| `openclaw_user_remark`（备注 = **本次开仓意图**） | 与区间**同时**写入（`cta_strategy_send_user_remark`）：`方向｜依据（形态证据+数值）｜目标位｜失效价｜时限｜前一手`——价格触发开仓时，意图已先在合同里，AI 每轮与复盘都按它核对本手动作，而不是事后补写 |
| `操作=立即` | 仅用于回踩/破位确认的那一刻，绝不用于"看到趋势再追" |
| `openclaw_notice` | 预置剧本（如"突破 X → 趋势多；跌破 Y → 只观察"），被唤醒的 AI 照剧本执行、不临场改戏 |

> 分工：`user_remark` 记**本手意图**（这一仗怎么打、何时认输）；`notice` 记**短期禁令与剧本**（什么不许做）。两者都在开仓前写好，仓位才有"意图先行"。

## 2 意图卡

### 2.0 形态识别与预测（每轮先跑这一段，输出"意图 + 置信度 + 触发线/失效线"）

**数据源分工（三层，不混用）**

| 层 | 来源 | 拿什么 | 干什么用 |
|:--|:--|:--|:--|
| ① 盘面事实（主） | vnpy_mcp：`get_history_bars`（多周期 K 线）、`get_tick`、`cta_strategy_get_status`、`cta_strategy_get_all_reason`、`cta_strategy_get_trades` | 本品种交易所 K 线 + 策略状态/留痕 | **形态识别只认这里**——与下单同源，算出的结构位/网格价与执行一致 |
| ② 背景与事件 | `get_market_data.py`：板块批次（`us-sectors`/`us-all`/`crypto-all`）、`--fetch-url calendar`、`--fetch-url product-all-info`、`--fetch-url web-indicators` | 板块强弱、经济日历、品种新闻与评级、市场指标 | 交叉验证方向、给禁开仓窗口、发现催化剂 |
| ③ 兜底 | `web_search` | ①②覆盖不到的突发消息（监管/黑天鹅/财报暴雷） | **只用于否决/禁开仓**，不产生开仓信号 |

**预测四步（每轮按序执行）**

```
① 取数：get_history_bars 拉 主周期 ≥60 根 + 1m；计算 §1.3 指标
   （NATR 60 根分位、箱体宽与距边界、EMA 快慢间距、RSI 背离、推进幅度、量能对比）
   同步拉：get_status（参数/阶段/冷却）、get_all_reason + get_trades（上一手）、
   get_market_data.py 板块批次 + calendar + product-all-info
② 形态打分（按 §1.3 阈值，三选一 + 空仓）：
   压缩态 ≥3 项            → 预测【趋势将启动】
   背离 或 触及 2~3 级结构位 → 预测【趋势将反转】
   回踩三条件全中           → 预测【趋势将延续】
   往返 ≥3 + 宽 2~5×NATR + EMA 缠绕 → 预测【区间将延续】
   全不满足                → 空仓观察
③ 交叉验证（只降置信 / 否决，不新增信号）：
   板块方向与品种判断相反 → 置信 −0.1，且禁止追突破
   日历显示重大事件落在持仓窗口内 → 禁开新仓
   新闻/评级突变与判断冲突（product-all-info 或 web_search）→ 本轮否决
④ 输出三件套：意图（§1.1 表）+ 置信度 + 触发线/失效线
   触发线 → 写进 首仓价格区间；失效线 → 写进 notice（预置剧本）
```

**预测结论 → 剧本入口**：趋势将启动/延续 → §2.1 剧本；拐点将现 → §2.2 子型 A；深跌将到位 → §2.2 子型 B；区间将延续 → §2.3 剧本。置信 <0.6 或两类形态都只满足一半 → 空仓观察，不选卡。

### 2.1 趋势（趋势跟随）—— 一把仓吃一段

**主题（`openclaw_main_approach`：由人工/外部宏观分析智能体经 MCP 写入，本模块只读核对）**

```
趋势跟随：突破回踩确认后一笔进场，跌破结构即空仓，不摊低成本，不做逆势抄底
```

| 参数名 | 标准名 | 值 | 通道 |
|:--|:--|:--:|:--|
| `first_part` | 建议首仓占比 | 0.8~1.0 | MCP |
| `martin_add_count` | 网格数量 | **0**（网格关闭；0 合法，每格量=0） | MCP |
| `martin_grid_distance` | 网格间距 | 0.03 | MCP |
| `enable_martin_add_open` | 是否允许网格主动开仓 | **true**（首仓靠它：CCI 同向 + 价格进区间自动开；关了=只能"立即"现价开=追） | MCP |
| `enable_martin_add_loss` | 是否允许亏损时网格加仓 | **false**（红线：绝不摊低成本） | MCP |
| `enable_martin_add_profit` | 是否允许盈利时网格加仓 | false | MCP |
| `enable_martin_sub` | 是否允许网格减仓 | false | MCP |
| `enable_stop_loss` | 是否允许止损 | **true** | MCP |
| `stop_loss_radio` | 止损幅度 | **0.02~0.05**（默认 0.03；超过=趋势形态预测错误，立砍；形态失效线） | MCP |
| `enable_atr_stop_loss` | 是否允许ATR动态止损 | **false**（3% 固定止损即形态失效线，ATR 兜底永不会先触发） | MCP |
| `atr_loss_period` / `atr_loss_multiple` | ATR周期 / 倍数 | 14 / 8~12（休眠，开关关） | MCP |
| `enable_stop_autoprofit` | 是否允许移动止盈 | **false**（窄回撤未到目标就洗出，宽回撤永不触发；盈亏比由固定止盈执行） | MCP |
| `stop_autoprofit_start_radio` / `stop_autoprofit_back_maxvalue` | 移动止盈启动 / 回撤 | —（休眠，开关关） | MCP |
| `enable_stop_profit` / `stop_profit_radio` | 是否允许止盈 / 止盈幅度 | **true** / **0.09~0.15**（=3~5× 止损，按默认 0.03 计；止损值变化时按 3~5 倍相应调整；到达即离场；**开关关则止盈幅度不生效**） | MCP |
| `enable_first_allow_prices` | 是否限制首仓价格区间 | **true** | MCP |
| `first_allow_price_max` | 首仓最高价 | =回踩区上沿 | MCP |
| `enable_allow_price_high` | 是否禁止追高 | true（持仓加仓防线，空仓不生效） | MCP |
| `base_direction` | 操作方向 | 1 / -1 | MCP |
| `enable_ema_cross_probe` | EMA金叉死叉探针 | true | MCP |
| `ema_probe_fast_window` / `ema_probe_slow_window` | EMA快 / 慢线周期 | 50 / 200 🎚 | MCP |
| `enable_atr_probe` | ATR波动率突变探针 | true | MCP |
| `enable_rsi_probe` / `enable_rsi_div_probe` | RSI 极端 / 背离探针 | **false** | MCP |
| `enable_cci_chance_only` | 仅允许CCI触发加减仓 | true（网格已关，仅一致性） | MCP |
| `openclaw_main_interval` | AI定时分析周期 | 180~240 🎚（**≤主周期**） | MCP |
| `close_cooldown_hours` | 平仓冷却（小时） | 48 | 人工 |
| `martin_k_time` / `cci_martin_period` / `target_delay_minute_max` | 网格K线 / CCI周期 / 成交等待分钟数 | 5 / 35 / 3 🎚 | 人工 |

**注意**
1. 空仓期唯一"不追高"闸门=`是否限制首仓价格区间` 上限；`操作=立即` 时现价不在区间内**根本不下单**。
2. 绝不能关固定止损（关则禁止开新仓）；**止损（默认 3%）即形态失效线**，不开 ATR 止损/移动止盈（两者在此止损制下都不成立）。
3. 两个加仓开关 false + `网格数量=0` = 明确"不使用网格"（主动开仓=true 是首仓入口，不是加仓）。
4. **盈亏比预期 ≥3:1（至 5:1）**：止损（0.02~0.05，默认 3%）⇒ 目标 = 3~5× 止损距离（默认 9~15%）；写合同时 ③目标 ≥3× 止损距离、⑥考核按此。
5. **失败模式四种，处置不同**：震荡打脸/做反趋势/买到末尾——交给 3% 形态失效线，不人工干预；**持仓期出现风险事件（财报/宏观数据/黑天鹅/板块级风险）——不等止损，立即 `操作=立即` 清仓（人工/MCP 下发）**，事后复盘归类为风险退出期。

**剧本（判定流程按 §2.0；判"正在形成"，不判"已经走完"）**

| 前置（提前埋好） | 触发（越线才动） | 否决（撤预案） |
|:--|:--|:--|
| 压缩态 ≥3 项（§1.3）→ **同时写好上破/下破两套区间**，操作=择机 | ①收盘突破 ≥1×ATR ②**回踩到位**（回撤 ≤0.5×突破幅度、缩量）③CCI 同向 | 无回踩直接走远 → **放弃这一波**（宁可错过，不追尾声）；反向破位 → 撤多头区间 |

### 2.2 反转（反向接货）—— 子型 A 抓V反 / 子型 B 阶段抄底

### 2.4 禁止清单（红线）

1. 突破当日市价追；2. 大阳/大阴线后入场；3. 连涨 N 根做多 / 连跌 N 根做空；4. 24h 分位 >0.85 或 <0.15 时新建仓；5. 用 EMA 交叉/突破本身当开仓触发；6. 探针一响就换意图（探针只叫醒）；7. 形态已破坏却不撤区间/不清电报（=漂）。

### 2.5 考核（写入 `openclaw_user_remark`）

**本次计划捕捉的交易机会，其考核条款写进合同**——与方向/目标位同一份 `openclaw_user_remark`，埋伏区间时同步写入。这样每轮 AI 自检、复盘打分都对照合同里的考核条款，而不是事后另立标准：

```
…｜时限=10根主周期K线｜前一手=…｜
考核：成功=3根K线内脱离成本 ≥1×ATR；失败=到期未脱离成本 或 跌破失效价 → 无条件风险退出
```

**各意图的考核判据（写合同时套用）**

| 意图 | 成功判据 | 失败判据 | 失败处置 |
|:--|:--|:--|:--|
| 趋势（§2.1） | 脱离成本 ≥3× 止损距离（默认止损下 ≥0.09，盈亏比≥3:1；至 5:1）→ 到达离场 | 触止损（=形态预测错）/ 到期未达目标 | 无条件风险退出 |
| 反转·A（§2.2） | 3~5 根内脱离成本区 | 触止损 / 加满上限仍未反弹 | 无条件风险退出 |
| 反转·B（§2.2） | 建满 4~6 格后修复到中轴分批走 | 浮亏 ≥1.5×计划止损 / 支撑失效 | 先降档，再风险退出 |
| 波动收波（§2.3） | 完成 ≥3 次"加→减"闭环 | 加仓触顶仍同向 / 区间被有效突破 | 清仓，考虑切意图 |

**评分规则**：每轮 AI 与复盘对照合同的考核条款打分——**有痕（合同写了考核、按条款处置）=改；无痕（没写考核、事后解释）=漂**。
**机制考核**：提前量连续 ≤0（形态走完才动作）→ 改 §1.4 的唤醒配置（`openclaw_main_interval`、探针组合）；验收只看**提前量**与**预案撤销率**。

## 3 切换意图

**场景迁移**：任意意图→另一意图：持仓满足 00-Index §1.3 **兼容三条件**（方向一致 / 仓位占比≤目标首仓占比上限 / 成本在目标入场纪律内）且**重大变化连续 2 轮确认** → 持仓期整套切换；不满足 → 先清仓到仓位=0 再切。任意→空仓（置信<0.6 连续 2 轮或结构破坏）。

### 3.1 必换 12 项

①`openclaw_main_approach`（**由人工/宏观分析智能体写入，本模块只核对**） ②`建议首仓占比` ③网格数量/间距/止盈 ④止损幅度+开关 ⑤止盈幅度+开关+移动止盈(启动/回撤) ⑥ATR 止损止盈+周期+倍数 ⑦四个网格开关（主动开仓/亏损加仓/盈利加仓/减仓） ⑧首仓价格区间+上下限 ⑨`base_direction` ⑩探针组合 ⑪`仅允许CCI触发加减仓` ⑫人工固定参数（如需不同值）

### 3.2 步骤

```
1. 确认仓位=0（空仓观察/等待首仓）
2. 操作=禁止（保证不下单）
3. **核对主题（不改主题）**：读 `策略核心思路`，确认已是目标意图文本——若不是，**本模块不修改主题**，停止切换并上报，由人工/外部宏观分析智能体经 MCP 写入
4. vnpy_mcp 写参数（3.1 的 ②~⑪）→ **读取验证（设置→读取闭环）**
5. 写合同：cta_strategy_send_user_remark("方向｜依据｜目标位｜失效价｜时限｜前一手")
6. 人工层参数如有差异 → UI 改（或停→删→重建）
7. 核验（3.3）全部通过 → 放闸：操作=择机 或 立即
```

### 3.3 核验表（任一不符不放闸）

| 检查项 | 期望 |
|:--|:--|
| 策略核心思路 | 非空且等于卡内文本 |
| 参数来源与闭环 | vnpy_mcp 设置后**已读回验证**（设置→读取闭环，以 MCP 设置为准，不是 AI 报告里的建议值） |
| 止损 | `是否允许止损=true` 且幅度=卡内值 |
| 止盈幅度 | 趋势 0.09~0.15（=3~5× 止损）；波动/反转按卡 |
| 网格三数值 | 与同一张卡匹配 |
| 方向与区间 | `base_direction` 与 `first_allow_price_max` 方向一致（做多给上限） |
| 探针 | 与卡一致（无多余探针） |
| AI 总开关 | `启用AI策略分析=true` |
| 冷却 | 若刚平仓且同向，确认是否落在冷却期 |

### 3.4 持仓期（pos≠0）禁止放大

| 参数 | 持仓期允许 |
|:--|:--|
| `建议首仓占比` | 只允许**收紧** |
| `网格数量` | 只允许**增大**（每格变细） |
| `网格间距` | 只允许**放大** |
| `止损幅度` | 只允许**收紧**（放宽=改意图→清仓） |
| `仅允许CCI触发加减仓` / 探针组合 | **不得改** |
| `是否允许卖出基础底仓` | 不可改（基线：不卖基础底仓） |

改任一须在 `参数修改理由` 写明 `人格内调整(收紧)` 或 `换意图(须清仓)`；无理由改动判漂。
