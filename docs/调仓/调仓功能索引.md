  - 三份报告：美股大盘与板块和资金流向分析（宏观基调）、美股做多/做空选股结果（交叉印证，不作调仓依据）

## 三、加密货币调仓文档

### 加密货币叙事板块轮动调仓文档组（索引：[加密货币/00_index.md](加密货币/00_index.md)，13 篇）

- **定位**：AI 可执行的币安 U 本位永续叙事板块轮动调仓方法论——先卖弱再买强、分批执行（避开资金费率结算窗口）、USDT 资金闭环；风险偏好 + 轮动阶段定方向，10 叙事板块 × 市值分桶双层评分选标的，风控兜底
- **结构**：00 索引与整体架构（含一次闭环判据）/ 01-03 风险偏好闸门 → 10 叙事板块评分 → 市值分桶子维度 / 04 策略名→币映射（S1–S5，权威矩阵）/ 05 调仓执行流程 / 06 策略资金分配（invest_mult 默认 1，B=USDT）/ 07 仓位约束与风控（高弹性合计 ≤15%）/ 08 拆单执行（7×24 时段）/ 09 双周期再平衡（月 ±20% / 周 ±5%）/ 10 AI 调仓输出模板（17 字段 JSON，中文 key）/ 11 失败陷阱 / 12 数据源与工具
- **报告名**：固定 `加密货币板块轮动调仓`，须与定时任务名、落盘文件夹名逐字一致（命名铁律见 README §6）
- **与美股组差异**：7×24 + 资金费率结算窗口（00/08/16 UTC ±30min 避开）；阈值放大（缺口 2% 不动 / 单轮幅度 20% / 不追高 5% / 不买暴涨 30%）；USDT 单币种（invest_mult 默认 1，B ≤ available × 2）；品种信息为空 → 策略名 + crypto_pool.json + get_all_contracts 交集映射
- **数据输入**：
  - 三份报告：加密货币大盘与板块和资金流向分析（宏观基调）、加密货币做多/做空选股结果（交叉印证，不作调仓依据）
  - `scripts/get_market_data.py --market crypto --batch crypto-all`（板块评分数据）+ Coinglass / tokenomist / DefiLlama（资金费率·解锁·TVL）
  - `scripts/crypto_pool.json`（固定池，55 币 / 10 板块 / T1–T3 + 市值分桶；维护见 [../加密货币选择/选币操作手册.md](../加密货币选择/选币操作手册.md) §3.4）
  - vnpy_mcp 实时：策略级持仓 / 账户级持仓核对 / USDT 资金口径
- **工具**：`scripts/rebalance_tools.py` v2.4（美股/加密货币共用一套内核与 verify 门；`--market 加密货币` 预设已落地：2% 不动 / 幅度 20 / B ≥ 1000 USDT / 账户杠杆 ×2 / 高弹性 15% / crypto_pool.json 池适配 / USDT 单币种 verify；验收测试 `tests/test_rebalance_tools_crypto.py`，美股回归 `tests/test_rebalance_tools_v2.py` + `tests/test_rebalance_tools_sweep.py`，详见 [加密货币/12_数据源与工具.md](加密货币/12_数据源与工具.md) §13.5）

## 四、通用约定（所有市场调仓）

1. 报告是**说明性的**：不自动下单，落地需老板授权
2. 强制全量重分析：不使用任何缓存（含 Redis 状态板），持仓只认 vnpy_mcp 实时返回，上轮结论不直接沿用
3. 输出 JSON 用中文 key，字段完整性铁律：取不到的填 missing/null，不得删字段
4. 资金闭环：卖出释放与买入使用必须对得上，剩余现金与 $ 口径一致
