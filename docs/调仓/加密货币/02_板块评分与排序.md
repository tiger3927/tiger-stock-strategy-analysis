# 加密货币板块轮动调仓 — 02 板块评分与排序

> 第二层文档。板块 = **10 个叙事板块**，单一事实源 = `scripts/crypto_pool.json` 的 `categories`（04 §6.1.2 映射依据；板块命名登记见 00 §4.6-1）。
> 与美股 GICS 11 板块的关键差异：叙事板块无官方分类、板块强度是「叙事 + 资金」复合体——因此评分加入**资金确认**因子、动量窗口缩短（20/7/5 日替代 12/6/3 个月）。

---

## §4.1 板块分类

| 板块 | 观察币（crypto-all 批次） | 叙事属性 |
|------|--------------------------|---------|
| L1 公链 | SOL, AVAX, SUI, NEAR, APT, HYPE | 核心 beta + 新叙事 |
| L2/模块化 | OP, ARB | ETH 生态衍生 |
| DeFi | AAVE, UNI, LDO, CRV, MKR | 链上「银行股」，TVL 验证 |
| Meme | DOGE, PEPE, WIF, BONK | 投机温度计（晚期顶部信号） |
| 基础设施/AI | LINK, TAO, AR, FET | 叙事驱动，与 AI 联动 |
| 交易所平台币 | BNB, CAKE | 生态 + 回购叙事 |
| 支付/隐私 | XRP, LTC, ZEC, XMR | 监管敏感 |
| RWA | ONDO | 机构化叙事 |
| GameFi | IMX | 高弹性小板块 |
| DePIN | IOTX | 新兴叙事 |

> **BTC/ETH 是方向锚（T1），不构成独立板块**：BTC.D / ETH-BTC 是总开关输入（01 §3.1），板块动量以 BTC 为超额基准。

---

## §4.2 多因子评分模型

**板块综合得分 = 0.30 × 动量因子 + 0.25 × 周期因子 + 0.20 × 资金确认 + 0.15 × 流动性 + 0.10 × 叙事催化剂**

### §4.2.1 动量因子（30%）

| 子指标 | 权重 | 计算方式 |
|--------|:---:|---------|
| 20 日超额 vs BTC | 50% | 板块观察币（池内该板块 T1/T2 币等权合成价）20 日收益率 − BTC 20 日收益率 |
| 7 日超额 vs BTC | 30% | 同上，7 日窗口 |
| 5 日相对强弱趋势 | 20% | 5 日超额为正且扩大 = 1；为正但收敛 = 0.5；为负 = 0 |

> 动量因子**只做确认不做发现**；纯动量排名 = 后视镜（01 §3.5.3）。

### §4.2.2 周期因子（25%）

| 板块 | 早期 | 中期 | 晚期 |
|------|:---:|:---:|:---:|
| L1 公链 | +2 | +1 | −1 |
| L2/模块化 | 0 | +2 | +1 |
| DeFi | 0 | +2 | −1 |
| Meme | −2 | 0 | +2 |
| 基础设施/AI | 0 | +1 | +1 |
| 交易所平台币 | +1 | 0 | −1 |
| 支付/隐私 | +1 | 0 | 0 |
| RWA | 0 | +1 | +1 |
| GameFi | −1 | 0 | +1 |
| DePIN | −1 | +1 | 0 |

> 本表是 01 §3.3 轮动阶段可检验定义的量化锚（口诀：BTC→ETH→L1→DeFi→Meme）。轮动阶段缺失时本因子中性化（全 0）并进「数据缺失与冲突」。

### §4.2.3 资金确认（20%）

| 子指标 | 权重 | 判定 |
|--------|:---:|------|
| 板块平均资金费率 | 40% | < 0.05%/8h 健康 = 1；0.05–0.1% 中性 = 0.5；> 0.1% 拥挤 = 0（**晚期 Meme 例外**：费率极高 + 7 日 >50% = 顶部信号，不是加分项） |
| TVL / 成交占比趋势 | 30% | TVL（DeFi/RWA）或板块成交额占比 20 日均 > 50 日均 = 1；下降 > 15% = 0 |
| OI 位置 | 30% | OI 52 周分位 < 40 = 1（空间足）；40–85 = 0.5；> 85 杠杆拥挤 = 0 |

> 费率/OI/TVL 来源：Coinglass / DefiLlama（web_fetch，12 §13.1）。任一子指标缺失 → 按可得子指标权重归一；全部缺失 → 因子取 0.5 中性并注记。

### §4.2.4 流动性（15%）

- 板块 24h 成交额占全市场比重 + 前 3 币盘口深度；
- 占比 < 1% 的板块记 0.5（流动性风险，07 §8.3 收紧其流动性上限）。

### §4.2.5 叙事催化剂（10%）

- 未来 30 天存在正向催化（重大升级 / 上币 / ETF 落地，**且未被价格充分反映**）= 1；
- 存在负向事件（30 天解锁 > 流通量 1%、下币公告）= 0；
- 无明确事件 = 0.5。
- **龙头确认规则**：板块要进 Top 3-4，必须龙头币（池内该板块 T2 首位）20 日超额 ≥ 0；否则该板块强制降为中性——龙头不动的普涨不可信。
  **执行细则（2026-09-15 验收复盘新增）**：
  1. **「T2 首位」的取法**＝`crypto_pool.json` 该板块 `categories.<板块>.T2` 的**第 1 个币**；**无 T2 的板块（如 DePIN）取池内首位（T3 第 1 个）**并在报告注明取法；
  2. **判定口径**＝该币 20 日收益 − BTC 20 日收益（日 K，标 as_of），与 `score` 的板块动量因子同源但**落在币级**（`score` 只做板块/分桶合成）；
  3. **工具（v2.4.1 落地）**：`rebalance_tools.py leaders --market 加密货币 --prices <每币日K> --strong "<score 的强势板块>"` → 输出逐板块「T2 首位 / 20 日收益 / 基准 20 日收益 / 20 日超额 / 通过 / 建议」＋「确认后强势板块 / 降档板块」。本步须在 00 §4.2 标准执行顺序中显式执行（`score`/`score2` 只做板块/分桶合成，**不含**龙头确认），并按 00 §4.6-4 把「工具输出 + 原因 + 条款 + score 原始清单差异」写进 `数据缺失与冲突`；`rebalance_audit --leaders` 会对账（漏降档 → 不通过）；
  4. **降档后的落位**：`分析摘要.强势板块` 写**降档后**的清单（`score` 原始清单在 `数据缺失与冲突` 留存并注明差异），`目标分配.<板块>.目标_pct` 按降档后档位给目标；
  5. **例外**：T1（BTC/ETH）不作板块龙头参与本规则（其是基准与流动性锚）。

## §4.3 板块排序与分层规则

- **强势板块（Top 3-4）**：超配/加仓（06 §7.3.1.2 强势区间）；
- **中性板块（中间 3-4 个）**：维持；
- **弱势板块（Bottom 3）**：低配/减仓；
- **连弱强制规则**：弱势板块连续 **2 周**排名 Bottom 3 → 板块内持仓**强制减仓 50%**；连续 **3 周** → **强制清仓**（05 §7.2.3 / 07 §8.2）；
- 评分频率：周度（更新动量 + 资金确认）/ 月度（全量重算，09 §10.1）；
- 强势板块必须满足「RS 曲线（板块合成价 / BTC）处于上行趋势」，否则降档。

**工具**：`rebalance_tools.py score` 在 `--market 加密货币` 适配后执行（预设：动量窗口 20/7/5 日、周期因子表 = §4.2.2、板块集合从 crypto_pool.json 派生、观察币 = 池内 T1/T2 且 yahoo_verified=true）；适配完成前按本文手工评分，手工值按 00 §4.6-4 留痕。
