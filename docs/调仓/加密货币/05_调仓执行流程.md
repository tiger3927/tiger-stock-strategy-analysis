# 加密货币板块轮动调仓 — 05 调仓执行流程

> 第五层文档。节奏与美股同构（先卖弱、后买强、资金闭环），差异：7×24 无休市（拆单期默认 1-3 日、可压缩）、买入阈值放大（不追高 5% / 不买暴涨 30%）、事件窗口 = 资金费率结算 + 重大事件。

---

## §7.1 总体流程（8 步）

```
Step 1  大盘总开关（01 §3.1–3.4）：风险偏好三档 + 轮动阶段 → 判定「只卖不买 / 正常 / 限制性调仓」
Step 2  板块评分（02 §4）：10 板块排序 → 强(Top 3-4) / 中 / 弱(Bottom 3)
Step 3  子维度评分（03 §5）：分桶分层 → 板块内强/弱
Step 4  持仓映射与分层（04 §6）：S1–S5 + 未映射持仓
Step 5  资金盘点 + fund（06 §7.3.1.1/.2）：B / 可用 / 策略槽位 / 目标分配 / 缺口
Step 6  先处理弱势（卖）：S5 → S4 → 弱势板块 S3，按 §7.2 生成减仓/清仓指令
Step 7  再处理强势（买）：S1 → S2，按 §7.3 用释放资金 + 可用资金 加仓/开仓
Step 8  风控校验 + 报告输出（07 §8 / 10 §11）：verify 通过 → 交付
```

> 资金盘点–缺口（Step 5）必须在 Step 6（卖）之前完成；**卖/买只是缺口的执行**（06 §7.3.1.3），不得「先买、后看要卖多少」。

## §7.2 处理弱势持仓（先卖）

### §7.2.1 减仓节奏

- Day 1：弱势板块持仓统一减仓 30%–50%；
- Day 2：若板块评分仍为弱势 → 再减 30%（剩余仓位的 30%）；
- Day 3：若板块连续 3 周 Bottom 3 → 清仓；
- **7×24 注记**：若全部指令均为小单（< 该币 24h 成交额 5%，08 §9.1），可压缩至 1 日执行；但「先卖后买」顺序与资金闭环不变，拆单时点避开资金费率结算窗口（08 §9.2）。

### §7.2.2 减仓优先级

1. 板块评分最低 → 2. 币级评分最低（04 §6.3 三道闸）→ 3. 仓位最重 → 4. 流动性最好

**事件加速**：解锁公告 / 下币公告 / 协议安全事故 → 该币减仓/清仓**不拆单**，Day 1 一次性执行（事件窗口 > 拆单纪律，11 §12.5）。

### §7.2.3 特殊情况处理

- 亏损币：板块持续弱势 → 止损减仓（**不因亏损而持有**）；短期回调（板块仍中/强）→ 可保留底仓；
- 资金费率 > 0.1%/8h 的多头持仓 → 持有成本侵蚀，减仓优先级上调（即使板块中性）；
- S5 内：币级相对最好的 Top 20% → 保留底仓观察（按 S4 处理）；Bottom 80% → 优先减仓/清仓。

## §7.3 处理强势持仓（后买）

### §7.3.1 任务参数与资金分配

→ 引用 [06_策略资金分配.md](06_策略资金分配.md) §7.3.1（任务参数 8 项 / 统一口径 B / 板块目标 % / 缺口 2% 不动 / 策略资金定数 / 闭环 6 条 / 买入端约束）。

### §7.3.2 加仓节奏

- Day 1：使用释放资金 + 可用资金增量的 50%；
- Day 2：若板块仍强势 → 使用 30%；
- Day 3：若板块仍强势 → 使用 20%（剩余保留现金缓冲）；
- 加仓途中板块转中性 → 停止后续批次，剩余转现金。

### §7.3.3 买入限制

| 规则 | 阈值 | 说明 |
|------|------|------|
| 不追高 | 币当日涨幅 > **5%** → 不买入 | 加密日均波动 3-8%，阈值自美股 3% 放大 |
| 不买暴涨过的 | 币 5 日涨幅 > **30%** → 不买入 | 7 日 50% 已是晚期顶部信号（11 §12.1） |
| 回踩买入 | 优先在币回踩 MA20 时买入 | get_market_data crypto tickers 或 get_history_bars |
| 分 3 档建仓 | 30% / 30% / 40% | 同一目标仓位拆 3 批（10 §11.2 分批计划）；**每批数量按该币 `volume_min_unit` 取整、末批补齐残差**（06 §7.3.1.2 / 08 §9.1） |
| 跟涨币 | 等板块内上涨币占比 > 60% 确认后再配 | 龙头先行、跟涨在后 |
| 费率板块 | 板块平均资金费率 > 0.1%/8h → 该板块不新开 | 成本 + 拥挤双重风险 |

**工具**：`rebalance_tools.py exec`（`--market 加密货币` 适配后执行：不追高 5% / 不买暴涨 30% 否决、流动性 ≤ 24h 成交额 1%（`--liquidity-pct` 可放宽，60+ 默认收紧 0.5%）、小/中/大单分档、滑点、时段检查）；适配完成前按本节 + 07 §8.3 手工核对并留痕。「否决」指令不得执行。

> **涨幅口径（2026-09-15 验收复盘新增）**：`当日涨幅 / 5 日涨幅` 一律以**实时口径**判定（`get_tick` 或 1h K 线，并在 `数据缺失与冲突` 标 as_of）；日 K 派生值仅作兜底，且必须写「截至 <末根日期>」—— 网关日 K 实测滞后 ~2 日（12 §13.6-1），用滞后日 K 判「当日涨幅」会把两日的涨幅当作当日涨幅（漏判追高）或反之（误杀）。两口径结论不一致时，**以实时口径为准**并留痕。

## §7.4 单日调仓示例

> 前提（轮动早期）：BTC.D 55% 且回落、ETH/BTC 5 日 +2.1%、DeFi TVL 连续 2 周 −12%。持仓 12 策略：DeFi 5 个（AAVE/UNI/LDO/CRV/MKR，合计市值 12,000 USDT）、L1 2 个（SOL 5,000 / AVAX 3,000）、其他板块 5 个。

| 项 | 值 |
|---|---|
| fund | balance 100,000 USDT，available 95,000，invest_mult=1 → B=100,000；base_capital=1000 → 槽位 100（硬顶 50 → 取 50） |
| 评分 | 弱 = DeFi（TVL 流出 + 费率负）；强 = L1 公链（早期 +2，20 日超额 +6pct） |
| 目标 | DeFi → 0%（目标资金 0）；L1 → 16%（目标 16,000，现有 8,000，缺口 +8,000） |
| 缺口 | DeFi 5 币 Σ缺口 −12,000；SOL +5,500 / AVAX +2,500；其余 7 个 \|缺口\| < 2%×B=2,000 → 维持 |
| 指令 | Day 1：DeFi 5 币各减 40%（释放 4,800）；SOL 加仓 30% 档；Day 2：DeFi 再减 30%（释放 2,880）；SOL 第 2 批；Day 3：DeFi 确认仍弱 → 清仓剩余；SOL/AVAX 第 3 批 |
| 资金匹配 | 卖出释放 12,000 ≥ 买入使用 8,000 ✓；剩余现金 85,000 ≥ B×5% ✓ |
| 校验 | verify：单板块 L1=16% ≤ 20% ✓；高弹性合计 = 0 ✓ → 通过 |
