# 加密货币板块轮动调仓 — 09 双周期再平衡机制

> 加密 7×24 无节假日，周期锚 = UTC 日历日。幅度参数与任务参数默认值对齐：月度 ±20%（= max_delta_pct 默认）、周度 ±5%。

---

## §10.1 月度大再平衡

- **每月 1 日执行**（1 日恰逢重大事件窗口 → 移至最近非事件日并注明，见 08 §9.2）；
- 全量重算：10 板块（02 §4）+ 全部分桶子维度（03 §5）+ 轮动阶段复判（01 §3.3）；
- 调仓幅度控制在 **±20%** 以内（= 任务参数 max_delta_pct 默认值）；
- 同步动作：选币池校准（mcap_bucket / yahoo_verified，`sync_crypto_pool.py`）+ 池外探测（选币操作手册 §3.4）+ 解锁日历刷新（04 §6.3-2）。

## §10.2 周度小幅微调

- **每周五执行**；
- 仅更新动量因子 + 资金确认（资金费率 / TVL / OI）+ 轮动阶段复核；周期因子、流动性、叙事催化剂不动；
- 板块从强势跌出 Top 5 → 小幅减仓；新进入 Top 3 → 小幅加仓；子维度（板块 × 分桶）跌出 Top 8 → 小幅减仓；
- **单次调仓幅度 ≤ ±5%**。

## §10.3 异常事件触发

| 事件 | 处理 |
|------|------|
| 轮动阶段切换（早期 ↔ 中期 ↔ 晚期） | 全量重算，视同月度大再平衡 |
| 风险偏好 → 收缩 | 只卖不买（01 §3.4），无幅度限制 |
| ETF / SEC 裁决、重大交易所事故 | 事件驱动：相关板块/币仓位重判 |
| 板块 30 天解锁 > 流通量 5% | 该板块停止新开 + 解锁周不加仓（07 §8.4 #8） |
| 24h 全市场爆仓 > $5 亿 | 停止新开仓，次周度复判 |

**工具**：`rebalance_tools.py cycle --date <执行日期> [--last-rebalance ...] [--trigger ...]`（`--market 加密货币` 适配后：跨月且本月未调 → 月度大再平衡（±20%）；周五 → 周度微调（±5%）；重叠时月度优先；`--trigger` 命中 → 事件驱动（建议值 = 任务参数默认 20））。适配完成前按本节手工判定。
