## §3.1 大盘环境与风险偏好三档

| 风险偏好 | 判定（满足 2 条） | 对调仓的影响 |
|---------|------------------|-------------|
| 正常（投机） | BTC 站上 MA20 且 MA20 > MA50；BTC.D 走平或下降；稳定币市值扩张 | 正常调仓，阈值标准执行 |
| 中性偏弱 | BTC 在 MA20 上下反复；BTC.D 上行；山寨 20 日跑输 BTC > 5pct | max_new 降至 0–1；强势板块目标 % 区间上限下调 1/3；执行阈值提高 |
| 收缩（防御） | BTC 跌破 MA50 且 BTC.D 快速上行；**或** 24h 全市场爆仓 > $5 亿 | **只卖不买**：只处理弱势持仓（05 §7.2），强势持仓一律「维持」 |

**口径与裁决（2026-09-15 复盘新增：同一数据两种读法 → 档位/参数漂移）**：

1. **BTC.D 窗口口径**：「走平或下降」（正常档 ②）与「上行」（中性偏弱档 ②）一律以大盘报告 `板块轮动.BTC_D.趋势` 的 **3 个月口径**为准；7 日口径仅在明显反向（|Δ| > 1pct）时作为**并列提示**写出，不单独作档位依据；
2. **并列取保守**：若同一组数据使两档各自都满足 2 条（典型：BTC 在 MA20 上下反复 + BTC.D 3 月微升 → 正常/中性偏弱并列）→ **取更保守的一档**，并在报告 `数据缺失与冲突` 写明「两档并列 + 取保守档 + 另一档下的参数差异（max_new / 目标仓位总和 / 板块目标带）」；
   **（2026-09-15 验收复盘补充）** BTC.D 的「3 个月 / 7 日」两种读法若**分别**使「正常」与「中性偏弱」成立，即**构成并列 → 一律取保守档**；不得因为 7 日读法的 \|Δ\| ≤ 1pct（第 1 条的门槛）而否掉这一并列 —— 第 1 条只约束「7 日口径能否写进报告正文」，**不约束并列裁决**。判定文本须把两种读法的各自满足条数都写出（如「正常 2/3（7 日口径）或 1/3（3 个月口径）」）；
3. **与大盘报告标签的关系**：大盘报告 `市场风格.风险偏好` 是**参考标签**，档位仍按本表客观判定；**两者不一致必须在 `数据缺失与冲突` 留痕**，禁止只引用 direction / 风险等级而回避该标签；
4. **数据时点**：判定所用的 BTC 现价 / MA20 / MA50 / BTC.D / 山寨 20 日超额必须各自写明 as_of（并入报告 `数据溯源`），**禁止把不同时点的价格与均线（如 9/12 的 MA20 配 9/15 的价格）混算**——这是 2026-09-15 复盘查出的实际事故；
5. **判定清单**：报告 `风控校验.大盘状态确认` 须列出三档各自的**满足条数与条目**（哪几条满足、哪几条不满足），不得只给结论。

**数据来源优先级**：

1. `cta_report_get(report_kind="加密货币大盘与板块和资金流向分析")`（存在且 < 3 日）→ 解析 `分析摘要`（direction / 风险观察分）、`板块轮动`（主线板块 / 流出板块 / 轮动阶段 / BTC_D / ETH_BTC 汇率）、`风险提示`、`宏观联动`（VIX / HYG_LQD / 与纳斯达克 30 日相关性）；
2. 缺失或 > 3 日 → **不执行大盘分析任务**，改用**价格结构降级闸门**：`crypto-all` 批次（BTC/ETH 的 52 周分位、均线）+ `web_fetch` 直取 BTC.D / TOTAL2 / 稳定币市值（各 1 次），并在报告 `分析摘要.大盘状态` 标注 `gate.source = price_structure_fallback`。

## §3.2 宏观联动信号

| 信号 | 数据源 | 频率 | 对调仓的含义 |
|------|--------|------|-------------|
| DXY 美元指数 | web_fetch（Investing / CME 页面） | 日 | 美元走强 + BTC 走弱 = 外部流动性流出，系统性降仓 |
| 美债 10Y | web_fetch | 日 | 利率高位 → 高弹性 60+ 分桶持续受压 |
| VIX | get_market_data us-all（^VIX）/ web_fetch | 日 | VIX > 30 → 避险，停止新买入（07 §8.2） |
| 与纳斯达克 30 日相关性 | 大盘报告「宏观联动」 | 周 | 相关性升高 → 山寨变「BTC 的 beta 代理」，叙事分化收窄，板块间分散度下降 |
| BTC/ETH ETF 净流入 | web_fetch（Farside / SoSoValue 页面） | 日 | 连续净流出 > $5 亿/日 → 机构撤退信号，强势板块目标下调 |
| 稳定币市值 | DefiLlama 页面 | 日 | 扩张 = 场外干火药入场（轮动前置指标） |

## §3.3 轮动阶段可操作化定义（早期 / 中期 / 晚期）

> 「早期/中期/晚期」**不许凭感觉填**，必须按以下可检验标准判定（引用 加密货币市场.md Step 2）。满足 **2 条及以上**即判定为该阶段。

| 阶段 | 可检验标准（满足 2 条即判定） |
|------|---------|
| **早期** | ① BTC 20 日涨幅 > ETH 5 个百分点以上 ② BTC.D 上升 ③ Meme 板块 20 日跑输大盘 |
| **中期** | ① ETH/BTC 汇率上升 ② L1 公链/DeFi 开始补涨 ③ BTC.D 从高点回落 ④ DeFi TVL 同步增长 |
| **晚期** | ① Meme 币 7 日涨幅 > 50% 且持续跑赢 ② BTC.D 快速下降（山寨季明确）③ 主流板块龙头滞涨而高弹性币补涨 ④ 资金费率全市场集体高企 |

> 口诀（「BTC 领涨 → ETH 跟涨 → L1 补涨 → DeFi 全面上涨 → Meme 暴涨 → 崩盘」）仅作阶段感参考；**本表标准是唯一判定依据**。阶段切换（如 中期 → 晚期）本身即再平衡触发条件（07 §8.4 #4）。

> **执行要求（2026-09-15 复盘新增）**：① 判定须**逐条列出「满足 / 未满足」**（例：早期—BTC.D 3 月升 ✓、Meme 跑输 ✓、BTC 20 日涨幅 > ETH 5pct ✗ → 2/3 → 早期），并写入 `分析摘要.轮动预测.所处阶段`；② 判定所用数据（BTC/ETH 20 日涨幅、BTC.D、Meme 20 日超额）须标 as_of 并写入 `数据溯源`；③ 与大盘报告 `板块轮动.轮动阶段` 不一致时，以本表客观标准为准并在 `数据缺失与冲突` 留痕。

## §3.4 大盘总开关规则

| 大盘状态 | 操作 |
|---------|------|
| 风险偏好收缩（§3.1） | **只卖不买**；总仓位逐步降至 50% × B 以下（07 §8.2） |
| 中性偏弱 | 正常卖弱 + 限制性买强：max_new −1、强势板块目标 % 区间上限 −1/3 |
| 正常 | 按标准流程执行（05 §7.1） |
| 晚期 + 资金费率全市场高企 | 停止新开仓；只允许减仓 / 清仓 |

> 操作模式 `mode`（auto / 积极 / 正常 / 防御）由本节三档驱动：正常→正常、中性偏弱→防御、收缩→「只卖不买」执行变体（06 任务参数表）。判定理由写入报告 `风控校验.大盘状态确认`。

## §3.5 机会发现（轮动预测）

> 与美股同纪律：轮动方向**不靠「谁涨得好」**，只抓轮动拐点或初期。「下一个轮入板块」直接决定 02 §4 的周期因子先验与 06 §7.3.1.2 的目标分配方向。

### §3.5.1 轮动预测判断矩阵（下一个轮入板块）

| 当前状态 | 预测轮入板块 | 判断依据 |
|---------|-------------|---------|
| BTC 领涨且 BTC.D 上升（早期） | 暂不追山寨，候补 L1 龙头（SOL/AVAX） | 资金仍在避险，山寨普涨尚未启动 |
| ETH/BTC 上行 + BTC.D 从高位回落（中期） | L1 公链 → DeFi | 增量资金向中高市值扩散 |
| 某板块 20 日跑输 BTC > 10pct 但资金费率转正 | 该板块的滞后补涨标的 | 资金开始关注，尚未拥挤 |
| Meme 板块 7 日涨幅 > 50% 且 OI 高位（晚期） | **转防御**：BTC / 稳定 / 不追高 | 投机泡沫特征，做多风险大于收益 |

### §3.5.2 拐点信号清单（时机：满足任一类才认定「拐点或初期」成立）

| 类别 | 信号 | 确认方式 |
|------|------|---------|
| 汇率拐点 | ETH/BTC 5 日累计 > 2% 且站上 MA20 | ETH-USD ÷ BTC-USD（crypto-all 批次） |
| 市占率拐点 | BTC.D 从 52 周高位回落 > 3pct | web_fetch CMC / CoinGecko 页面 |
| 板块相对强弱拐点 | 某板块 20 日超额 vs BTC 由负转正 + 板块内上涨币占比 > 50% | crypto-all 批次板块观察币合成 |
| 资金流入确认 | 板块平均资金费率转正 + 稳定币市值连续 3 周扩张 | Coinglass + DefiLlama |
| 事件催化 | 重大升级 / 上币 / ETF 裁决（尚未被价格充分反映） | 12 §13.1 事件源；「见光死」（已充分反映）必须排除 |

### §3.5.3 反后视镜纪律

- 禁止把「近期涨幅榜 Top」直接当轮动方向——必须能回答「驱动是什么、处在领先→滞后哪一段」；
- 已走完的行情（Meme 7 日 >50%、高弹性币普涨）只作「晚期确认」，是**减仓/防守依据**，不是轮入依据（11 §12.1）；
- 龙头不动、只有高弹性币乱涨的板块行情不可信（02 §4.2.5 龙头确认规则）；
- 轮动预测统一记录在本节，其余章节只引用、不另设。
