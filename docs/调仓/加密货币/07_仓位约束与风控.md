# 加密货币板块轮动调仓 — 07 仓位约束与风控

> 第六层文档。所有 % 上限分母 = **总预算 B**（06 §7.3.1.2 统一口径）。
> 与美股的差异：无「单子板块 12%」（币的「子维度」= 市值分桶，改用**高弹性合计上限**）；止损主战场在策略层（martin 参数管理），组合层管「拿哪个板块、拿多重」，不重复管策略内止损。

---

## §8.1 硬性仓位上限

| 约束项 | 上限 | 说明 |
|--------|:---:|------|
| 单板块总仓位 | ≤ 20% × B | 触顶截断、余额分给未触顶板块（06 §7.3.1.2） |
| **高弹性合计（31-60 + 60+ 分桶）** | **≤ 15% × B** | 币小市值总风险上限（替代美股 T3 合计 5% + 单子板块 12%） |
| 单只 60+ 分桶币 | ≤ 2% × B | 极端高弹性单币上限 |
| 单只 31-60 分桶币 | ≤ 3% × B | 04 §6.3-3 |
| 单只币仓位 | ≤ 5% × B | 全分桶通用 |
| 前 3 大板块合计 | ≤ 50% × B | 按调仓后板块 % 降序取前三，列三分项明细 |
| 最大策略数量 | ≤ 50 | = B ÷ base_capital 硬顶 |
| 现金最低比例 | ≥ 5% × B | 仅 invest_mult = 1；invest_mult > 1 时按闭环 ② 检查 |
| 弱势板块 + 强势子维度 | 仓位上限减半 | 03 §5.4 |

> **与最小可下单量的冲突处置（2026-09-15 新增）**：若按上述上限算出的单币目标资金 < 该币最小可下单名义额（= `volume_min_unit` × 现价），则该币「不可开」——并入同板块其他币；同板块亦不可开 → 该板块本轮目标 = 当前值（06 §7.3.1.2）。**不得为凑上限反向抬高目标资金**（00 §4.6-6 禁止对门拟合）。

## §8.2 止损 / 风控规则

| 触发条件 | 操作 | 层级 |
|---------|------|:---:|
| 单币亏损 > 8% | 止损（策略内，martin 止损参数管理） | 策略层 |
| 板块评分连续 2 周 Bottom 3 | 板块内持仓减仓 50% | 组合层 |
| 连续 3 周 Bottom 3 | 清仓 | 组合层 |
| BTC 跌破 MA200（或风险偏好 → 收缩） | 总仓位降至 50% × B 以下 | 组合层 |
| 24h 全市场爆仓 > $5 亿 | 停止新开仓，存量按 01 §3.1 复判 | 组合层 |
| 板块平均资金费率 > 0.1%/8h | 该板块停止新开；单币费率 > 0.1% 的多头减仓优先 | 组合层 |
| VIX > 30（跨市场避险） | 停止所有新买入（对照美股 VIX 规则） | 组合层 |

> 组合层**不管理**策略内止损/止盈/移动止盈/网格（均为 martin 策略参数，见 10 §11.2 调仓相关参数）；组合层只管「拿哪个板块、拿多重、何时退出板块」。

## §8.3 流动性风控

- 单日单币买卖金额 ≤ 该币 **24h 成交额 × 1%**（币的流动性口径 = 24h 成交额，取 get_market_data crypto tickers 的 `avg_volume` 或 CoinGecko `total_volume`；无数据 → 按 60+ 档 0.5% 处理并注明）；
- **60+ 分桶默认收紧至 0.5%**（深度薄）；
- 超限 → 指令「否决」（exec 工具 `--liquidity-pct` 放宽须在 `意图备注` 说明理由）。

## §8.4 再平衡触发条件

| # | 触发条件 | 周期 |
|:-:|---------|------|
| 1 | 月度（每月 1 日；加密 7×24 无节假日） | 月度大再平衡 ±20% |
| 2 | Top 3 板块变更 | 周度 / 事件 |
| 3 | Top 6 子维度（板块 × 分桶组合）变更 > 3 个 | 周度 |
| 4 | 轮动阶段切换（早期 ↔ 中期 ↔ 晚期，01 §3.3） | 事件 |
| 5 | 单板块仓位 > 20% | 随时 |
| 6 | 高弹性合计 > 15% | 随时 |
| 7 | 大盘进入防御模式（01 §3.4） | 随时 |
| 8 | 重大事件：ETF/SEC 裁决、重大交易所事故、板块 30 天解锁 > 流通量 5% | 事件 |

**工具**：`rebalance_tools.py cycle`（`--market 加密货币` 适配后：月度 ±20% / 周五 ±5% / 事件驱动建议值 = 任务参数默认 20；`--trigger` 枚举对应本表 #2–#8）；适配完成前按本表手工判定并在报告注明。
