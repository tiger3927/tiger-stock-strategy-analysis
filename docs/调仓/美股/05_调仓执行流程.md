# 美股板块轮动调仓 — 第五层：调仓执行流程

> 美股板块轮动调仓文档组 · [索引](00_index.md)
> 输入：评分排序 + 持仓分层 + 资金缺口 → 输出：先卖弱/后买强的调仓指令与报告
> 资金分配已单独成文：[06_策略资金分配.md](06_策略资金分配.md)

---

### 7.1 总体流程

```
Step 1: 宏观判定 → cta_report_get 拉取大盘 + 美股做多/做空报告（见 04_持仓映射与分层.md §6），确定操作模式（积极/正常/防御），轮动预测与做多/做空报告交叉印证（01_宏观环境定基调.md §3.5）
Step 2: 板块评分 → 输出 11 板块排序
Step 3: 持仓映射 + 资金盘点 → 用 vnpy_mcp `cta_strategies_get_all`（+ `get_positions` 核对）读取实际策略持仓，映射到板块并分层（详见 04_持仓映射与分层.md §6.1）；同时读取账户级与策略级资金（见 06_策略资金分配.md §7.3.1.1）
Step 4: 目标分配与缺口 → 确定板块/个股/策略目标分配（见 06_策略资金分配.md §7.3.1.2/.3），缺口 = 目标 − 当前
Step 5: 先处理弱势持仓（减仓/清仓，缺口中的减/清部分）
Step 6: 计算释放资金，再处理强势持仓（加仓/新开，缺口中的加/开部分；资金闭环自检 06_策略资金分配.md §7.3.1.5）
Step 7: 风控校验（含资金闭环，06_策略资金分配.md §7.3.1.5）
Step 8: 输出调仓报告 JSON（含任务参数、资金现状、目标分配、分批计划、调仓相关参数与意图备注，模板见 10_AI调仓输出模板.md §11.1）
```

### 7.2 处理弱势持仓（先卖）

**原则：先卖后买，资金闭环，绝不同时操作**

#### 7.2.1 减仓节奏

```
Day 1: 弱势板块持仓统一减仓 30%-50%
Day 2: 若板块评分仍为弱势 → 再减 30%（剩余仓位的 30%）
Day 3: 若板块评分连续 3 周 Bottom 3 → 清仓
```

#### 7.2.2 减仓优先级

```
优先减仓顺序：
1. 板块评分最低的板块中的个股
2. 个股评分最低的个股
3. 仓位最重的个股（降低集中度）
4. 流动性最好的个股（容易卖出）
```

#### 7.2.3 特殊情况处理

```
IF 个股处于盈利状态:
    正常减仓，锁定利润
IF 个股处于亏损状态:
    若板块持续弱势 → 止损减仓（不因亏损而持有）
    若板块只是短期回调 → 可保留底仓观察
IF 个股有重大利好（财报超预期、新产品获批等）:
    即使板块弱势，可保留底仓
```

### 7.3 处理强势持仓（后买）

#### 7.3.1 任务参数与资金分配（从现状到目标）

> **资金分配是调仓计算的核心**："先卖弱、再买强"只是执行节奏，"配多少、配给谁"由本节决定。五步：① 资金盘点 → ② 目标分配 → ③ 缺口 → ④ 策略资金定数 → ⑤ 资金闭环自检。
> 注意：①–③ 必须在本文档 §7.1 的 Step 5（卖）之前完成——卖/买只是缺口的执行。

**详见 [06_策略资金分配.md](06_策略资金分配.md)**：7.3.1.1 资金现状（含币种规则）→ 7.3.1.2 目标分配（板块 → 个股 → 策略）→ 7.3.1.3 缺口计算 → 7.3.1.4 策略资金定数（初始资金 / 资金调整）→ 7.3.1.5 资金闭环自检（六条）→ 7.3.1.6 买入端执行约束。

#### 7.3.2 加仓节奏

```
Day 1: 使用释放资金的 50% 进行加仓
Day 2: 若板块仍强势 → 使用 30%
Day 3: 若板块仍强势 → 使用 20%
（剩余资金保留为现金缓冲）
```

#### 7.3.3 买入限制

```
买入限制条件：
- 不追高：个股当日涨幅 > 3% 时不买入
- 不买暴涨过的：个股 5 日涨幅 > 15% 时不买入
- 回踩买入：优先在个股回踩 20 日均线时买入
- 分 3 档建仓：30% / 30% / 40%，分批入场
```

> **工具（exec）**：执行计划 JSON（`[{"名称","ticker","方向","金额","日均成交额","当日涨幅_pct","五日涨幅_pct","平均价差_pct","执行时间ET","价格","MA20"}, ...]`）整理好后执行 `python scripts/rebalance_tools.py exec --plan <文件>.json`，逐指令输出 否决原因/提示 + 拆单计划（08 §9.1 三档）+ 预期滑点 + 时段提示；「否决」指令不得执行；减仓/加仓/建仓节奏（§7.2.1/§7.3.2/§7.3.3）作为参考块随工具输出。

### 7.4 单日调仓示例

```
假设你有 40 只持仓，分布在 11 个板块：

板块评分结果：
  强势板块：科技(XLK)、金融(XLF)、工业(XLI)
  弱势板块：能源(XLE)、材料(XLB)、房地产(XLRE)

持仓映射：
  弱势板块持仓：12 只（能源 4 只 + 材料 5 只 + 房地产 3 只）
  中性/强势板块持仓：28 只

AI 当日执行：
  1. 12 只弱势持仓 → 统一减仓 40%
  2. 释放资金约 15% 总仓位
  3. 从释放资金中，分配：
     - 科技板块：加仓已持有的 2 只优质股
     - 金融板块：加仓已持有的 1 只 + 新开 1 只
  4. 新增持仓不超过 2 只
  5. 总仓位保持稳定（约 85%-90%）
  6. 剩余资金保留为现金缓冲（10%-15%）
```

> 本例为 `invest_mult = 1`（无保证金）情形，此时总预算 B = 权益，满仓 = 100% B = 100% 权益；`invest_mult > 1` 时总预算 B = 权益 × invest_mult，满仓 = 100% B = 权益的 invest_mult 倍（06_策略资金分配.md §7.3.1.2 统一口径）。

### 7.5 报告输出（调仓 JSON）

本模块只负责**生成调仓报告 JSON**；vnpy_mcp 在本模块中只承担**读取**职责（持仓、账户、成交、策略状态，见 04_持仓映射与分层.md §6.1.1）。

| 环节 | 手段 |
|------|------|
| 读取现状 | vnpy_mcp 查询工具（**只读**）：持仓、账户、成交、策略状态 |
| 决策 | 板块/子板块评分 + 持仓映射分层（§4–§6，见 02/03/04 文档） |
| 输出 | **调仓报告 JSON**（模板见 10_AI调仓输出模板.md §11.1，字段见 §11.2） |

> **这份 JSON 是说明性报告**：供人阅读、复盘与决策参考；凡与本次调仓有关的信息（含资金额度、止盈止损、网格、意图备注）都可如实写清。
> **写全即完整**：需要新增策略 → 写进「新增策略」；需要交代意图 → 写进每条指令的「意图备注」。
