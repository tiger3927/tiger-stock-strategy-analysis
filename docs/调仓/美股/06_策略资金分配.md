# 美股板块轮动调仓 — 任务参数与资金分配

> 美股板块轮动调仓文档组 · [索引](00_index.md)
> 调仓计算的核心：资金盘点 → 目标分配 → 缺口 → 策略资金定数 → 资金闭环自检 → 买入端约束
> 所属流程见 [05_调仓执行流程.md](05_调仓执行流程.md) §7.3；必须在 §7.1 Step 5（卖）之前完成 ①–③

---

**任务参数**（在任务提示词中给出，省略用默认值；本次实际取值必须写入报告「任务参数」块）：

| 参数 | 默认 | 范围 | 含义 | 作用 |
|------|------|------|------|------|
| `invest_mult` 投入倍率 | 2 | 1–5 | 目标组合初始资金总和 = 账户权益（`balance`）× 该值；1 = 不用保证金，>1 = 使用 IB 保证金（IB 上限 5 倍） | 7.3.1.2/.4/.5 |
| `mode` 操作模式 | auto | auto / 积极 / 正常 / 防御 | auto = 跟随大盘报告（01_宏观环境定基调.md §3.4）；手动指定则覆盖 | 7.3.1.2 板块目标区间表 |
| `max_delta_pct` 单轮调仓幅度上限 | 10 | 3–10 | 单轮 Σ\|目标−当前\| / 总预算 ≤ 该值；周度微调 3，月度/全量 10 | 7.3.1.3 |
| `max_new` 本轮新仓只数 | 2 | 0–3 | 本轮允许的新开仓数量 | 7.3.1.3/.6 |
| `max_single_pct` 单票上限 | 5 | 1–10 | 单只个股仓位上限（占总预算 %） | 7.3.1.2 |
| `max_sector_pct` 单板块上限 | 20 | 10–30 | 单个板块仓位上限（占总预算 %） | 7.3.1.2 |
| `base_capital` 每策略基准资金 | 10000 | 5000–50000 | 每策略基准资金额度 (USD)：最小开仓门槛 + 分配单位；单票目标资金 < 1 个基准单位 → 不开，并入同板块其他票 | 7.3.1.2/.3 |
| `max_strategies` 策略总数上限 | auto | ≤50 | 目标组合策略总数（股票只数）；auto = 总预算 B ÷ base_capital（例：B=30万、基准=1万 → 30 个，平均每个 1 个基准单位），硬顶 50（07_仓位约束与风控.md §8.1 管理复杂度） | 7.3.1.2/.3/.4 |

> **全文统一口径（唯一分母）**：所有仓位 %（板块 / 个股 / 总仓位 / 前三 / 单轮幅度 / 现金下限）分母一律为**总预算 B = 权益 `get_accounts.balance` × `invest_mult`**。`invest_mult = 1` 时 B = balance，与无杠杆口径完全一致；`invest_mult > 1` 时红线随 B 等比放大（总仓位 100% = 权益的 `invest_mult` 倍，即保证金满配）。本文不再单独使用"总资产"作分母——"总资产"仅指 `balance` 本身（权益 = 持仓占用 + 可用现金），是总预算的基数，不是分母。

### 7.3.1.1 资金现状（vnpy_mcp，工具见 04_持仓映射与分层.md §6.1.1 / 12_数据源与工具.md §13.4）

| 层级 | 工具 | 取什么 | 用途 |
|------|------|--------|------|
| 账户级 | `get_accounts` | `balance`（权益，总预算基数）、`available`（可用现金）、`frozen` | 仓位百分比分母 = balance × invest_mult（总预算 B，§7.3.1.2）、现金缓冲来源 |
| 策略级 | `cta_strategies_get_all` | 每策略 `可用资金总量`、`已使用资金占比`、`实际持仓`、`持仓目标` | 各策略资金池与可用空间 |

- 必须写入报告「资金现状」块（模板 10_AI调仓输出模板.md §11.1）：账户级全写；策略级只列**本次调仓涉及的策略**（加仓 / 新开 / 减仓 / 清仓 / 维持），其余一行"N 只未涉及策略"
- 可用空间 (USD) ≈ `可用资金总量` × (1 − `已使用资金占比`)
- 已有策略要加仓而资金池不足（可用空间 < 缺口）→ 除"加仓"指令外必须附 `资金调整`（见 7.3.1.4）

**币种规则（IB 账户）**：
- `get_accounts` 返回可能含**多币种条目**（IB 多币种账户：accountid / currency 字段区分，如 USD / HKD / CNY）
- **本模块所有金额一律美元口径**（美股以美元计价）：优先取 **USD 币种条目**的 `balance` / `available` 作基准
- 无独立 USD 条目、只有本位币（如 HKD）→ 按当前 USD/本位币汇率换算为美元，并在「资金现状」块记录所用汇率与时点（汇率来源：web-indicators / 行情数据脚本或联网查询，须可查证）
- **禁止**把不同币种条目直接相加，或用非 USD 条目作仓位百分比分母

**Step 0 — 资金框架工具（必调，7.3.1.2/.4/.5 的计算基准）**

7.3.1.1 取数完成后、目标分配之前，必须先运行资金框架工具生成资金框架，**以工具输出为计算基准**（本章公式作为手工核对参考，以及工具不可用时的回退）：

```
python scripts/rebalance_tools.py --balance <权益> --available <可用现金> \
  --invest-mult <投入倍率> --mode <操作模式> --max-delta-pct <单轮调仓幅度上限> \
  --max-new <本轮新仓只数> --max-single-pct <单票上限> --max-sector-pct <单板块上限> \
  --base-capital <每策略基准资金> --max-strategies <策略总数上限>
```

- 8 项任务参数按任务提示词实际取值给出（省略用上表默认值）；`--balance` / `--available` 取 7.3.1.1 账户级值（USD 口径，先执行币种规则）
- 工具自动做参数自检（`每策略基准资金 ≤ 单票上限%×B`），违反时按 §7.3.1.2 补救规则自动调整并留痕；**AI 须把 `调整记录`（原值 → 新值 + 规则）写入报告「任务参数」块**
- `成功=false` 处理：
  - 参数自检不通过（未自动调参时）→ 用自动调参模式重跑，或与用户确认参数变更
  - 账户规模低于方法论最小要求（B < 50000）→ **终止本次调仓**，并在「执行建议」说明原因
  - 策略总数上限过小 → 调大 `max_strategies` 重跑（工具会给出所需数量）
- JSON 输出 → 报告块映射：

| 工具 JSON 字段 | 报告块 | 说明 |
|------|------|------|
| `输入 / 任务参数` | 任务参数 | 工具实际采用值（含自动调整后的） |
| `参数自检 / 调整记录` | 任务参数（备注） | 有调整必须写入 |
| `预算`（总预算B / 目标仓位总和 / 保证金占用 / 购买力上限） | 资金汇总 | B 为全文 % 分母 |
| `策略槽位`（策略数 / 组合 / 每策略目标资金 / 初始资金） | 目标分配（骨架）+ 资金汇总（策略初始资金合计 / 目标组合策略数 / 策略数上限） | AI 在此框架上填板块 / 个股维度 |
| `策略槽位 / 板块落法示例` | 目标分配（参考） | 仅示例；实际板块 % 按 §7.3.1.2 区间表 |
| `资金闭环自检`（6 条） | 风控校验（预算 / 保证金 / 来源 / 缓冲项） | `全部通过`=true 才可输出报告 |

> **一致性注意**：工具与本章是同一规则的两套实现；参数默认值 / 公式变更时，**scripts/rebalance_tools.py 与本章必须同步修改**。

### 7.3.1.2 目标分配（板块 → 个股 → 策略）

**总预算**（全文唯一仓位分母，由 `invest_mult` 驱动，IB 保证金账户）：

```
总预算 B = 权益（get_accounts.balance）× invest_mult              # 目标：Σ 各策略初始资金；全文 % 分母
目标仓位总和 = B ÷ 1.2                                            # 1.2 为每策略缓冲（见 7.3.1.4）
保证金占用 = max(0, 目标仓位总和 − 可用现金)                       # invest_mult>1 且现金占比低时启用
```

**板块目标 %**（操作模式 × 板块评分档；`mode=auto` 未触发 07_仓位约束与风控.md §8.2 防御时默认"正常"列，均受 07_仓位约束与风控.md §8.1 硬上限约束）：

| 板块评分 | 正常 | 积极 | 防御 |
|---------|------|------|------|
| 强势（Top 3） | 12%–20% | 15%–20% | 5%–10% |
| 中性 | 5%–12% | 8%–15% | 2%–8% |
| 弱势（Bottom 3） | 0%–5% | 0%–5% | 0%–3% |

- 区间内取值由机会场景强度（[01_宏观环境定基调.md](01_宏观环境定基调.md) §3.5 场景库置信度、与做多/做空报告交叉印证程度）决定；**分配依据必须写入报告「目标分配」块**（板块 + 当前 % + 目标 % + 依据）
- **预算归一化**：各板块目标 % 之和 = S；若 S × 总预算 B ≠ 目标仓位总和 → 系数 k = 目标仓位总和 / (S × B) 等比缩放全部板块；缩放后仍须满足 `max_sector_pct` / 前三大板块 ≤50% / 单票 `max_single_pct`，触顶则截断、余额分给未触顶板块
- 弱势且当前有持仓的板块 → 目标 = 0（卖出，见 05_调仓执行流程.md §7.2）

**个股目标 %**（板块内）：
- 每板块 1-2 只（见 7.3.1.6），T1 龙头目标 ≥ T2 中盘
- 硬上限：单票 ≤ `max_single_pct`（单只 Tier 3 ≤1%，07_仓位约束与风控.md §8.1）；板块内个股目标之和 = 板块目标 %（必须相等）
- **最小开仓门槛**：单票目标资金 = 个股目标 % × 总预算 B ≥ `base_capital`（1 个基准单位）；不足 1 单位 → 不开，并入同板块其他票（原因写入「意图备注」）。**自检**：须满足 `base_capital ≤ max_single_pct% × B`（默认 base_capital=1 万、max_single_pct=5% → 要求 B ≥ 20 万，B 低于此值时优先调低 base_capital，如 5000），否则门槛与单票上限互斥

**取整损失条款（2026-09-15 新增）**

「目标资金」有两个口径，**必须分清，不得混用**：

| 口径 | 定义 | 用途 |
|------|------|------|
| **决策口径** | 桩模板「目标资金」= 个股目标 % × B（**未取整**）；指令中可显式写 `目标资金` 字段 | 最小开仓门槛、初始资金 × 1.2 缓冲的**判定基准** |
| **落地口径** | `目标持仓 × 现价` = `目标仓位占比_pct × B`（**整股取整后**） | 实际下单金额、资金闭环（买入使用） |

- 目标持仓 = 决策口径目标资金 ÷ 现价，**向下取整**；取整后金额低于决策口径属正常（取整损失），**不构成门槛不达标**。
- 当「落地口径 < base_capital 而决策口径 ≥ base_capital」时，在指令中补写 `目标资金`（决策口径）字段，verify 即按决策口径判定；**不得**为了让门槛通过而反向抬高股数或改写目标资金。
- 若决策口径本身 < 1 个基准单位 → 按上文"不开，并入同板块其他票"处理，**不得向上取整凑够门槛**。
- **策略总数**：目标组合策略总数 ≤ `max_strategies`（= B ÷ base_capital，硬顶 50）；超出 → 按个股评分保高弃低（T1 优先），其余并入或不开

**策略目标资金 (USD)** = 个股目标 % × 总预算 B（= `get_accounts.balance` × invest_mult）——即该股票策略 `初始资金` 参数的目标值（见 7.3.1.4）

### 7.3.1.3 缺口计算（目标 − 当前 → 调仓方向）

```
对每只股票：缺口 = 策略目标资金 − 当前持仓市值
  缺口 > 0 且板块强势       → 加仓（新仓占本轮 ≤ max_new 个名额，且目标资金 ≥ base_capital，见 7.3.1.6）
  缺口 < 0 且板块弱/中性   → 减仓 / 清仓（见 05_调仓执行流程.md §7.2）
  |缺口| < B 的 1%        → 维持（不动，防过度交易，见 11_常见失败陷阱.md §12.2）
```

- **幅度上限**：Σ\|缺口\| / 总预算 B ≤ `max_delta_pct`（默认 10%）；超出 → 按缺口绝对值从大到小处理，达到上限的其余票转「维持 + 触发条件」
- 各板块个股指令的目标 % 之和必须与「目标分配」块一致（防个股指令与板块目标漂移）

### 7.3.1.4 策略资金定数（初始资金 / 资金调整）

| 情形 | 规则 |
|------|------|
| 所有策略（已有加仓 / 新增） | `初始资金` = 个股目标资金 × 1.2（上限值，目标仓位 ≈ 初始资金的 83%，余量为手续费/滑点/止损缓冲），取整 |
| 已有策略加仓 | 若 `初始资金` 大于该策略当前 `可用资金总量` → 差值即增资金额（写入 `资金调整`）；若小于 → 不削减（资金不收回，富余写入「说明」） |
| 减仓 / 清仓 | 不动 `初始资金`，只调 `持仓目标` / `操作方向` |

- **总量核对**：Σ `初始资金` = B = 权益 `balance` × `invest_mult`（任务参数），天然 ≤ 权益 × 5（IB 保证金上限）
- **策略数核对**：目标组合策略总数 N ≤ `max_strategies` = B ÷ `base_capital`（硬顶 50，07_仓位约束与风控.md §8.1）；即平均 B/N ≥ base_capital（每个策略 ≥ 1 个基准单位），单策略 ≥ 1 单位
- 防御模式（或 S&P 破 200 日线，07_仓位约束与风控.md §8.2）：目标仓位总和（正常 = B÷1.2）另压至 ≤ B × 50%
- 超预算 → 按「新仓名额 → 单票目标 → 板块目标」顺序压缩，并在「执行建议」中记录压缩过程

### 7.3.1.5 资金闭环自检（输出前必须全部通过，对应 10_AI调仓输出模板.md §11.2 规则 5）

> Step 0 工具（fund）已算好第 1/2/5/6 条（JSON `资金闭环自检` / `全部通过`）；第 3/4 条由 `gap` 子命令按缺口快照算出（输出 `资金匹配` + `闭环3_资金来源` + `闭环4_现金下限`，对应报告「资金汇总」卖出释放/买入使用/净额/剩余现金）；AI 须核对全部通过并写入报告「风控校验」，以下条目为核对参考。

1. **预算**：Σ 各策略 `初始资金` ≤ 总预算 B = 权益 `balance` × `invest_mult`（任务参数，默认 2 倍）
2. **IB 保证金上限（券商物理约束）**：Σ 各策略 `初始资金` ≤ 购买力 `available` × 5（IB 杠杆硬顶，`invest_mult` ≤ 5 时自动满足；此为券商可动用购买力上限，与百分比分母 B 是不同概念，不得互代）
3. **资金来源**：本轮 `买入使用` ≤ 本轮 `卖出释放` + 可用现金 `available` × `invest_mult`；「资金来源」必须写清（卖出哪只 / 可用现金 / 保证金）
4. **现金下限（仅无保证金）**：`invest_mult = 1` 时，剩余现金 = 可用现金 + 卖出释放 − 买入使用 ≥ B × 5%（07_仓位约束与风控.md §8.1，此处 B = balance）；`invest_mult > 1` 时现金可为负（保证金占用），此项不适用
5. **每策略缓冲**：每条指令 / 新增策略的 `初始资金` ≥ 个股目标资金 × 1.2（防满仓无缓冲）
6. **基准与数量**：每策略目标资金 ≥ `base_capital`（最小开仓门槛）；策略总数 N ≤ B ÷ `base_capital`（硬顶 50）

### 7.3.1.6 买入端执行约束（释放资金分配规则）

```
释放资金分配规则：
1. 只流入当天排名 Top 2-3 的强势板块
2. 每个强势板块只加仓 1-2 只个股
3. 优先加仓已持有的优质标的（不开过多新仓）
4. 新开仓不超过 2 只（防止持仓数量爆炸）
5. 板块内**优先加仓已放量突破的龙头**（选股池 T1 / 市值 Top）；跟涨股等广度确认（>60% 上涨）后再配
```
