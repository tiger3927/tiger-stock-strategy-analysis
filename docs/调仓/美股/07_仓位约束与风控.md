### 8.1 硬性仓位上限

> 下表所有 % 上限分母一律 = **总预算 B = 权益 × invest_mult**（06_策略资金分配.md §7.3.1.2 统一口径）；`invest_mult = 1` 时 B = 权益，数值与旧口径一致。

| 约束项 | 上限 | 说明 |
|-------|------|------|
| 单个板块 (Sector) 总仓位 | ≤ 20% | 防止板块系统性风险 |
| 单个子板块 (Industry Group) 总仓位 | ≤ 12% | 防止子板块过度集中 |
| 单只个股仓位 | ≤ 5% | 防止个股黑天鹅 |
| Tier 3 小盘股总仓位 | ≤ 5% | 小盘股高风险，总量控制 |
| 单只 Tier 3 小盘股仓位 | ≤ 1% | 单只小盘股严格限制 |
| 前 3 大板块合计 | ≤ 50% | 防止过度集中 |
| 现金最低比例 | ≥ 5% | 仅无保证金（invest_mult=1）适用；保证金（invest_mult>1）时现金可为负，改按 06_策略资金分配.md §7.3.1.5 预算/上限校验 |
| 最大持仓数量 | ≤ 50 只 | 管理复杂度上限 |

### 8.2 止损规则

| 触发条件 | 操作 |
|---------|------|
| 个股亏损 > 8% | 强制止损 |
| 板块评分连续 2 周 Bottom 3 | 板块内持仓减仓 50% |
| 板块评分连续 3 周 Bottom 3 | 板块内持仓清仓 |
| S&P 500 跌破 200 日均线 | 总仓位降至 50% 以下 |
| VIX > 30 | 停止所有买入操作 |

### 8.3 流动性风控

```
单日单只个股买卖金额 ≤ 该股日均成交额 × 1%
（防止冲击成本过大）

示例：
  AAPL 日均成交额 = 100 亿美元
  单日最大买卖 AAPL 金额 = 1 亿美元（对散户 AI 可放宽）
```

> **工具（exec）**：`python scripts/rebalance_tools.py exec --plan <文件>.json [--liquidity-pct N]` 逐指令校验「单日单只买卖金额 ≤ 日均成交额 × N%」；默认 N=1，散户放宽（如 5/20）时传 `--liquidity-pct`；超限指令输出「否决」。

### 8.4 再平衡触发条件

```
满足以下任一条件即触发再平衡：
1. 月度固定再平衡（每月第一个交易日）
2. 板块评分发生重大变化（Top 3 板块变更）
3. 子板块评分发生重大变化（Top 6 子板块变更超过 3 个）
4. 宏观阶段切换信号出现
5. 单板块仓位超过 20% 上限
6. 单子板块仓位超过 12% 上限
7. 大盘进入防御模式
```

> **工具（cycle）**：`python scripts/rebalance_tools.py cycle --date <执行日期> [--last-rebalance <上次调仓日期>] [--trigger <触发条件>]` 做日期算术判定双周期窗口（跨月未调 → 月度；周五 → 周度；重叠月度优先；`--trigger` 枚举对应上文 2-7 及异常事件 → 事件驱动），输出 `max_delta_pct建议`（月度 10 / 周度 3 / 事件驱动 10 / 无固定周期 null）。
