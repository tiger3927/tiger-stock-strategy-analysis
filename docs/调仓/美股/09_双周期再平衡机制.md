# 美股板块轮动调仓 — 双周期再平衡机制

> 美股板块轮动调仓文档组 · [索引](00_index.md)
> 触发节奏：月度大再平衡 / 周度小幅微调 / 异常事件即时评估

---

### 10.1 月度大再平衡

```
每月第一个交易日执行：
1. 全面重新计算 11 板块多因子评分
2. 全面重新计算 29 子板块多因子评分
3. 重新排序并确定强势/中性/弱势板块及子板块
4. 全面调整板块及子板块权重至目标配置
5. 调仓幅度控制在 ±10% 以内（避免过度换手）
```

### 10.2 周度小幅微调

```
每周五执行：
1. 更新板块评分（仅更新动量因子和情绪因子）
2. 更新子板块评分（仅更新动量因子和情绪因子）
3. 检查是否有板块排名发生重大变化
4. 检查是否有子板块排名发生重大变化
5. 如有板块从强势跌出 Top 5 → 小幅减仓
6. 如有板块新进入 Top 3 → 小幅加仓
7. 如有子板块从强势跌出 Top 8 → 小幅减仓
8. 单次调仓幅度不超过 ±3%
```

### 10.3 异常事件触发

```
以下事件触发即时评估（非固定周期）：
1. 美联储利率决议
2. 重大经济数据发布（非农、CPI、GDP）
3. 地缘政治事件
4. 板块内重大并购/监管变化
```

> **工具（cycle）**：`python scripts/rebalance_tools.py cycle --date <执行日期> [--last-rebalance <上次调仓日期>] [--trigger top3_change|subsector_top6_change|macro_switch|sector_over_cap|subsector_over_cap|defensive_mode|abnormal_event]` 做日期算术：跨月且本月未调 → 月度大再平衡（±10%）；周五 → 周度微调（±3%）；重叠时月度优先；`--trigger` 命中 → 事件驱动（建议值 = 任务参数默认 10，双周期机制未对事件设专属幅度）。是否「每月第一个交易日」由 AI 按交易日历判定（工具无法感知节假日），非首个交易日则为补做。
