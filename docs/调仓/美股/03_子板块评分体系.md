### 5.1 为什么需要子板块粒度

GICS Level 1（11 个 Sector）在某些场景下粒度太粗：

```
示例：2023-2024 AI 行情
  信息技术 (XLK) 整体强势
  但内部：半导体设备 +80%，软件 +20%，硬件 +10%
  如果只按 XLK 评分 → 整个板块都加仓
  如果按子板块评分 → 只加仓半导体，不加仓软件/硬件
```

**子板块轮动的核心价值**：在强势板块中精确定位最强细分领域，在弱势板块中识别可能逆势的细分赛道。

### 5.3 双层评分模型

```
最终子板块得分 = 0.50 × 所属 Sector 得分 + 0.50 × 子板块独立得分
```

#### 5.3.1 子板块独立得分

与 Sector 评分使用相同的多因子模型，但数据源为子板块级别：

```
子板块独立得分 = 0.30 × 子板块动量 + 0.25 × 经济周期因子
               + 0.20 × 子板块价值 + 0.15 × 子板块质量 + 0.10 × 子板块情绪
```

**动量因子计算**：

```
子板块 RS = 子板块价格（等权合成）/ SPY 价格
子板块 RS_ROC = (RS_today / RS_n_days_ago - 1) × 100
```

对于没有独立 ETF 的子板块，使用成分股等权合成价格指数：

```
子板块价格 = 成分股价格等权平均
成分股选择：该子板块内市值 Top 5 或流动性 Top 5 的个股
```

#### 5.3.2 双层评分决策矩阵

> **矩阵只有一份，权威定义在 [04_持仓映射与分层.md](04_持仓映射与分层.md) §6.2**（覆盖 板块 × 子板块 全部 9 种组合，并映射到 S1–S5）。
> 本节**不再重复表格**，避免两份矩阵漂移（2026-09-15 事故：03 与 04 两张矩阵不等价，同一持仓在两个模块得到不同结论）。
>
> 子板块评分场景下的对照关系（由 `score2` 的 `决策` 字段给出）：
> - 板块强 + 子板块强 → **S1 强烈加仓**（板块-子板块共振）
> - 板块强 + 子板块弱 → **S3 维持**（仅保留，不加仓）
> - 板块弱 + 子板块强 → **S4 保留底仓观察**
> - 板块弱 + 子板块弱 → **S5 优先减仓/清仓**（双重弱势）

### 5.4 子板块排序与分层

```
对所有 29 个子板块进行评分并排序：

强势子板块（Top 6-8）：综合得分最高 → 超配
中性子板块（中间 10-12）：维持权重
弱势子板块（Bottom 5-7）：低配 / 减仓

附加规则：
- 子板块评分不得高于其所属 Sector 评分超过 1 个标准差
  （防止子板块过度偏离板块基本面）
- 若 Sector 为弱势但子板块为强势 → 子板块仓位上限减半
```

> **工具（score2）**：子板块等权合成价格序列（SPY + 各子板块，`{日期: 收盘}`；无独立 ETF 的子板块由 AI 用成分股市值/流动性 Top5 等权合成 §5.3.1）整理好后执行 `python scripts/rebalance_tools.py score2 --prices <文件>.json --sector-score <score 输出.json> [--cycle 周期阶段]`：板块映射以 stock_pool.json 为准；最终得分 = 0.5×板块得分 + 0.5×独立得分（§5.3，缺板块评分时退化为独立得分）；§5.3.2 决策矩阵逐子板块给结论（强烈加仓/仅保留不加仓/保留底仓观察/优先减仓清仓）；Top 6-8/Bottom 5-7 分层（默认 7/6，`--top-strong/--bottom-weak` 可调）；钳制按「板块得分 + 1×板块得分分布总体标准差」（§5.4）；板块弱+子板块强自动提示仓位上限减半。板块得分缺失/子板块未映射 均进「数据缺失」，不静默。

### 5.5 子板块轮动的典型场景

```
场景一：科技板块 (XLK) 内部轮动
  Sector 评分：科技 = 强势（排名第 2）
  子板块评分：
    - 半导体与半导体设备 = 强势（排名第 1）
    - 软件与服务 = 中性（排名第 10）
    - 技术硬件与设备 = 弱势（排名第 20）
  操作：加仓半导体，维持软件，减仓硬件

场景二：医疗板块 (XLV) 内部轮动
  Sector 评分：医疗 = 中性（排名第 6）
  子板块评分：
    - 制药与生物科技 = 强势（排名第 5）
    - 医疗设备与服务 = 弱势（排名第 18）
  操作：加仓生物科技，减仓医疗设备
```

> 注：本节的"场景"是**评分应用示例**（评分出来之后怎么操作），**不是机会发现场景**；预测（发现机会）的场景库统一在 [01_宏观环境定基调.md](01_宏观环境定基调.md) §3.5。
