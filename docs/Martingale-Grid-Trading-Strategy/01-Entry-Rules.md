## 一、价格校准规则

### 1.1 概念定义

| 概念 | 定义 |
|:--|:--|
| 三级支撑位 | 近三个月价格触及后反弹的三个成交密集区，按距当前价格由近到远排列 |
| 三级压力位 | 近三个月价格触及后回落的三个成交密集区，按距当前价格由近到远排列 |
| 理想首仓价格区间 | 一级支撑位至一级支撑位上方约 1.5%~2% 的范围 |
| 可接受首仓最高价 | 理想首仓价格区间上沿上方约 1%~2% |
| 禁止追高价格 | 可接受首仓最高价之上，风险收益比已跌破 1.8。做空时方向相反 |
| 风险收益比（做多） | (一级压力位 - 当前价格) / (当前价格 - 一级支撑位) |
| 风险收益比（做空） | (当前价格 - 一级支撑位) / (一级压力位 - 当前价格) |

### 1.2 做多首仓：价格位置与操作对应关系

```
支撑区 ←──理想首仓──→ 可接受区 ←──观望区──→ 压力区
  ↑          ↑           ↑        ↑         ↑
一级支撑    理想上沿     可接受上沿   禁止追高    一级压力

理想首仓区间：立即建仓，建议首仓占比 0.20 ~ 0.30
可接受区间：择机建仓，建议首仓占比 0.10 ~ 0.20
观望区间（距支撑 > 3% 或距压力 < 3%）：禁止建仓，等待回落
```

### 1.3 做多禁止条件

以下任一条触发，禁止大幅首仓：

1. 距一级支撑位 > 3%
2. 距一级压力位 < 3%
3. 处于近 5 日区间上半部
4. 刚经历急涨（近 2 日涨幅 > 5% 且无回调）
5. 近 24 小时触及区间上沿
6. 风险收益比 < 1.8
7. 未来一周存在重大不确定事件（引用 calendar 全局事件 + product-all-info 个股事件新闻）
8. 预测置信度 < 0.65
9. 成交量在接近压力位时明显萎缩（上攻无力）

### 1.4 做空首仓：价格位置与操作对应关系

```
压力区 ←──理想首仓──→ 可接受区 ←──观望区──→ 支撑区
  ↑          ↑           ↑        ↑         ↑
一级压力    理想下沿     可接受下沿   禁止追空    一级支撑

理想首仓区间：立即建空仓，建议首仓占比 0.15 ~ 0.25
可接受区间：择机建空仓，建议首仓占比 0.08 ~ 0.15
观望区间：禁止建空仓，等待反弹
```

### 1.5 做空禁止条件

1. 距一级压力位 > 3%
2. 距一级支撑位 < 3%
3. 处于近 5 日区间下半部
4. 大盘牛市（引用大盘分析报告趋势判断）或股票基本面优良（引用 product-all-info 新闻/评级）（做空大型牛股是自杀行为）
5. 风险收益比 < 1.8
6. 预测置信度 < 0.65

### 1.6 通用规则

所有价格数据必须逻辑自洽：当前价格、近 24 小时区间、近三个月区间、三级支撑位、三级压力位——任意两者之间的相对关系必须合理。

### 1.7 例外机制

以上禁止条件为默认规则。当预测置信度 ≥ 0.82 且存在强外部催化剂（重大利好/利空落地→product-all-info 新闻、机构大额进出→product-all-info 评级、板块强共振→大盘分析报告、宏观转向→大盘分析报告等），AI 可建议有限突破个别条件。必须在理由中：

1. 明确突破哪条禁止条件
2. 说明外部催化剂的实质内容
3. 说明如何对冲突破带来的额外风险

## 二、首仓择时规则

### 2.1 首仓建议的三种取值

| 取值 | 含义 | 适用条件 |
|:--|:--|:--|
| 禁止 | 当前价格不适合任何首仓操作。不建仓，不试探。 | 价格不在理想/可接受区间，或触发任一禁止条件 |
| 择机 | 价格已在可接受范围内，等待 CCI 等小周期信号确认后入场。 | 价格在可接受区间但非理想区间，或理想区间但缺少小周期确认 |
| 立即 | 价格已处于低风险首仓区，不等待信号，立即建仓。 | 价格位于理想首仓区间，CCI 方向一致（product-all-info technical.cci_14），成交量配合，无事件风险（calendar + product-all-info 新闻），置信度 ≥ 0.75 |

### 2.2 做多首仓决策维度

| 维度 | AI 需综合判断的要点 |
|:--|:--|
| 1. 价格位置 | 距支撑位和压力位的距离，处于理想 / 可接受 / 观望哪个区间（参见 §1.2） |
| 2. 风险收益比 | 引用 product-all-info technical 的 risk_reward_long |
| 3. 趋势方向 | 趋势枚举 + 技术结构（CCI→product-all-info technical.cci_14、均线→us-all、量能）+ 外部分析师共识（product-all-info 评级） |
| 4. 外部风险事件 | 财报→product-all-info 新闻、宏观数据→calendar、重大不确定性 |
| 5. 板块与大盘联动 | 引用大盘分析报告中的板块轮动 + 大盘趋势 |
| 6. 预测置信度 | < 0.65 时需格外谨慎 |

> AI 无需逐项打分，而是形成整体综合判断，在理由中说明各维度权重（例如：价格位置 40%、外部催化剂 35%、趋势方向 25%）。

### 2.2b 做空首仓决策维度

| 维度 | AI 需综合判断的要点 |
|:--|:--|
| 1. 价格位置 | 距压力位和支撑位的距离，处于理想 / 可接受 / 观望哪个区间（参见 §1.4） |
| 2. 风险收益比 | 引用 product-all-info technical 的 risk_reward_short |
| 3. 趋势方向 | 趋势枚举 + 技术结构 + 外部分析师共识（product-all-info 评级） |
| 4. 外部风险事件 | 财报→product-all-info 新闻、宏观数据→calendar、重大不确定性 |
| 5. 板块与大盘联动 | 引用大盘分析报告中的板块轮动 + 大盘趋势（牛市禁止做空需特别警惕） |
| 6. 预测置信度 | < 0.65 时需格外谨慎 |

> AI 无需逐项打分，而是形成整体综合判断，在理由中说明各维度权重。


### 2.3 思维陷阱——反复警惕的错误推理

| 陷阱 | 正确认知 |
|:--|:--|
| 「这股长期看涨，现在买没问题」 | 看涨 ≠ 当前价格适合首仓。差价越大，网格效率越低。 |
| 「这股长期看跌，现在空没问题」 | 看跌 ≠ 当前价格适合首空。差价越大，网格效率越低。 |
| 「好公司、好赛道，不怕拿」 | 好公司 ≠ 任何时候都是好买点。好公司买贵了，网格照样摊不平。 |
| 「未来一周可能涨，先建仓占位置」 | 方向预测 ≠ 入场时点选择。先在高位建仓，再等回调，已经伤了策略根基。 |
| 「未来一周可能跌，先建空仓占位置」 | 方向预测 ≠ 入场时点选择。先在低位建空仓，再等反弹，已经伤了策略根基。 |
| 「技术指标看着还行，买一点试试」 | 指标信号 ≠ 价格安全。少量试探仓也会随着不利波动触发加仓，形成真实风险。 |
| 「技术指标看着还行，空一点试试」 | 指标信号 ≠ 价格安全。做空试探仓随着不利上涨触发加空仓，同样形成真实风险。 |

## 三、信号强度 → 仓位映射

### 3.1 仓位核心公式

```
首仓量 = 总资金 × 建议首仓占比
每格加仓量 = 总资金 × (1 − 建议首仓占比) ÷ 网格数量
总仓位上限 = 满资金（网格全档触发时接近满仓）
```

> 策略代码**没有"最大仓位占比"参数**：总资金池 = 首仓（建议首仓占比）+ 网格加仓池（1 − 建议首仓占比），网格池按"网格数量"等份切分，每次加仓受满资金上限约束。

- 首仓只动用建议首仓占比，其余资金是网格加仓池；首仓占比 = 1.0 意味着一次性满仓、无加仓能力
- 满资金是上限，不是目标——实际动用多少取决于行情触发了几档网格，全档触发才接近满仓
- 首仓位置不理想时，优先降建议首仓占比，而非放宽价格标准
- 执行端量公式（代码如何实际计算首仓量/每格加仓量/最大可持仓量，含最小单位对齐）见 [Tiger-Grid-Template 07 §一](../Tiger-Grid-Template/07_trade_control.md)

### 3.2 做多仓位映射

| 信号组合 | 建议首仓占比 | 网格深度建议 |
|:--|:--|:--|
| 价格在理想首仓区 + CCI 底部确认（product-all-info technical.cci_14）+ 量能放大 + 板块共振（大盘分析报告）+ 无事件风险（calendar + product-all-info 新闻） | 0.25 ~ 0.35 | 深网格（8~12 档） |
| 价格在理想首仓区 + CCI 底部确认 + 量能配合（少 1-2 项） | 0.20 ~ 0.30 | 深网格（6~8 档） |
| 价格在可接受区间 + CCI 偏弱 + 量能一般 | 0.10 ~ 0.20 | 中网格（5~6 档） |
| 价格在可接受区间但 CCI 未确认 + 存在小事件风险（product-all-info 新闻） | 0.10 ~ 0.15 | 浅网格（3~4 档） |
| 价格不在区间内，或触发任何禁止条件 | 0（不建仓） | 不建仓 |
| 标的质量差、支撑压力模糊、波动率不适合网格 | 0（不建仓） | 不建仓 |

> 注：策略代码没有"最大仓位占比"参数（总仓位上限恒为满资金）。信号弱时靠**不建仓 / 降首仓占比 / 浅网格**控制风险敞口——浅网格 = 可接住的不利深度小，避免在错误趋势里深度摊平。

### 3.3 做空仓位映射

做空仓位应比做多更保守：

| 信号组合 | 建议首仓占比 | 网格深度建议 |
|:--|:--|:--|
| 价格在理想首空区 + CCI 顶背离（product-all-info technical.cci_14）+ 板块共振（大盘分析报告）+ 大盘偏弱（大盘分析报告趋势判断） | 0.15 ~ 0.25 | 中网格（5~6 档） |
| 价格在可接受区间 + CCI 超买 + 大盘中性（大盘分析报告） | 0.10 ~ 0.15 | 浅网格（3~4 档） |
| 条件部分缺失，或大盘偏牛（大盘分析报告） | 0（不建仓） | 不建仓 |
| 任何禁止条件触发 | 0（不建仓） | 不建仓 |

> **动态调整：** 以上为基准映射。AI 可根据市场体制（牛市/熊市/高波动期）、标的基本面质量和外部信息强度，在 ±0.10 范围内动态调整建议首仓占比（代码约束下限 0.1），并相应调整网格数量。

## 四、最小交易单位容差规则

股票、ETF 等品种存在最小交易单位，可能导致实际建仓金额无法精确等于目标金额。用于判断仓位是否「有效建立」，避免策略卡在「首仓建立中」无法流转。

### 4.1 核心公式

```
每手金额 = 当前价格 × 每手股数
实际可买手数 = floor(建议首仓金额 / 每手金额)  或  ceil(建议首仓金额 / 每手金额)
实际首仓金额 = 实际可买手数 × 每手金额
实际首仓占比 = 实际首仓金额 / 总资金
```

### 4.2 容差判断三层规则（按优先级）

| 优先级 | 规则 | 条件 | 结果 |
|:--:|:--|:--|:--|
| 1 | **价格优先原则** | 价格已回升至非理想区，且实际仓位 ≥ 建议首仓占比 × 0.90 | 视为有效建立，流转至「网格管理期」，不得追高补仓 |
| 2 | **一手容差原则** | 实际首仓占比 ≥ 建议首仓占比 - 每手金额/总资金（差额不足一手） | 视为有效建立，流转至「网格管理期」 |
| 3 | **深度不足原则** | 价格仍在有利区间，但差额 ≥ 一手金额，且实际仓位 < 建议首仓占比 × 0.85 | 停留在「首仓建立中」，等待有利价格补仓 |

### 4.3 示例

```
总资金 = 100,000，建议首仓占比 = 0.25 → 目标金额 = 25,000
股价 = 123.45，每手金额 = 12,345

可选方案：
  200股 = 24,690（占比 24.69%，差额 310）
  300股 = 37,035（占比 37.04%，超额 12,035）

规则2判定：24.69% ≥ 25% - 12.345% = 12.655% ✓ → 差额不足一手
→ 视为有效建立，进入「网格管理期」
```

```
总资金 = 100,000，建议首仓占比 = 0.25 → 目标金额 = 25,000
股价 = 450.00，每手金额 = 45,000

可选方案：0股 或 100股 = 45,000（占比 45%）

规则3判定：0% < 25% × 0.85 = 21.25% → 差额远超一手
→ 若价格在有利区间，继续等待建仓机会
→ 若价格已回升至非理想区，规则1判定：0% < 25% × 0.90 = 22.5% → 无法有效建立，退回「等待首仓」
```

## 五、阶段 JSON 示例模板（等待首仓 / 首仓建立中）

示例展示各阶段**该输出哪些参数、怎么组合**（完整字段清单见 [00-Router §五](00-Router.md) 模板，阶段×参数权限见 [00-Router §4.4](00-Router.md)）。

### 5.1 等待首仓 — 等回踩，允许 CCI 主动开仓

```json
{
  "趋势枚举": "震荡偏多",
  "策略阶段": "等待首仓",
  "操作": "择机",
  "操作方向": "多",
  "三级支撑位": [1164.4, 1140.0, 1110.0],
  "三级压力位": [1184.4, 1203.1, 1225.0],
  "首仓价格区间": [1164.4, 1184.4],
  "禁止追高价格": 1184.4,
  "是否限制首仓价格区间": true,
  "是否禁止追高": true,
  "建议首仓占比": 0.2,
  "是否允许网格主动开仓": true,
  "是否允许止盈": true,
  "是否允许移动止盈": true,
  "是否允许止损": true,
  "网格间距": 0.025,
  "网格数量": 8,
  "网格止盈": 0.03,
  "理由": "价格高于首仓区间上沿，等回踩 1164.4-1184.4。允许 CCI 主动开仓（择机=不立即下单，价格回到区间内由 CCI 自动开首仓；若想等更明确时机可输出 false）。三保护开关按等待首仓阶段基线输出 true（该阶段强制开，输出 false 不会被采纳，无仓时不触发、开仓即保护）。网格参数为本轮预配置，首仓建立后按此运行。"
}
```

> **组合要点：** `操作=择机` 本身**不再隐含**打开 CCI 开仓通道——必须同时输出 `是否允许网格主动开仓: true`，两者配合才会在回踩时自动开仓；`操作=立即` 时该通道被强制配对开（无需输出此字段，输出 false 会被覆盖并留痕）；`操作=禁止` 时强制关。`是否限制首仓价格区间/是否禁止追高` 控制价格约束的启用（false=清空约束）。

### 5.2 首仓建立中 — 补首仓，加仓通道显式决策

```json
{
  "趋势枚举": "看涨",
  "策略阶段": "首仓建立中",
  "操作": "择机",
  "操作方向": "多",
  "建议首仓占比": 0.2,
  "首仓价格区间": [1164.4, 1184.4],
  "是否限制首仓价格区间": true,
  "禁止追高价格": 1184.4,
  "是否禁止追高": true,
  "止损幅度": 0.096,
  "是否允许止盈": false,
  "是否允许移动止盈": false,
  "是否允许止损": true,
  "是否允许盈利时网格加仓": true,
  "是否允许亏损时网格加仓": false,
  "网格间距": 0.025,
  "网格数量": 8,
  "网格止盈": 0.03,
  "理由": "首仓低于建议占比，价格在区间内。择机=不立即补仓下单，等 CCI 择机加仓。盈利时允许网格加仓（true）、亏损时禁止加仓（false）——两个开关独立决策，不再由操作隐含。止盈/移动止盈为首仓建立中阶段基线强制关。"
}
```

> **组合要点：** 首仓建立中只允许止损（止盈/移动止盈强制关）；`是否允许盈利时网格加仓` 与 `是否允许亏损时网格加仓` 在"择机"时由你显式决策（可只开一个）；"立即"= 马上补仓下单（不改变加仓开关）。
