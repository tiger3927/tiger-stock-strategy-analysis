# 意图与操作手法快速参考

> **定位**：把"想干什么"（意图）快速映射为"**策略阶段 + 操作 + 主要参数组合**"。
> 这是手法手册（playbook），不是协议——字段格式与权限以 [00-Router.md](00-Router.md) §四/§五 为准，建仓细则见 01，网格细则见 02，离场细则见 03。
>
> **盘面数据来源**：接有实盘 vnpy_mcp 工具时，先取数再定参数（见 §九）；取不到数据时用 `cta_strategy_get_status` 里的策略自报状态 + `cta_strategy_get_all_reason` 里的历史理由。
>
> **只用主要参数**：每种场景只列该场景真正起作用的字段，其余按 00-Router §五 模板默认处理。

## 〇、通用纪律（每次输出前默念一遍）

1. **单轮指令语义**：参数每轮先复位再落地——想让某参数持续生效，**每轮都要重复输出**（网格间距/数量/格盈、ATR 周期/倍数、分批比例、`用户或者智能体的备注`=开仓意图等）；MCP 通道（`cta_strategy_set_parameters`，source=mcp）例外，是持久基线。**开仓意图备注**："等待首仓"必填（一句话目的/预期/退出条件），持仓各轮重复输出原意图（新特别事项追加在后）；全清仓时已了结的意图被系统自动清除，风险退出期写的清仓原因保留为空仓观察上下文（见 00-Router §4.5-6）。
2. **止损幅度有公式**：`止损幅度 ≈ 网格间距 × 网格数量 × 0.6`——开网格前必须能算出这个数，且 ≤ 可承受总亏损；算不出来就减网格数量。
3. **资金切分**：首仓量 = 总资金 × 建议首仓占比；每格量 = 总资金 × (1 − 建议首仓占比) ÷ 网格数量。占比 0.1-1.0，网格数量 1-50，间距 0.01-0.2，格盈 0.01-0.5。
4. **操作字段语义**（只管订单事件，与开关解耦）：
   - 等待首仓：立即=马上开仓（**当前价必须在首仓价格区间内**）；择机=不下单等 CCI（配 `是否允许网格主动开仓`）；禁止=不下单+主动开仓强制关
   - 首仓建立中：立即=补仓下单；择机=等 CCI（配加仓开关）；禁止=不下单+加仓开关强制关
   - **网格管理期：立即/禁止=无动作**（别指望用"立即"在网格管理期触发任何下单！）
   - 利润收割期：立即=立即清仓；择机=不下单，按网格规则出货
   - 风险退出期：立即/禁止=立即清仓；择机=仅盈利时 CCI 择机出货，**亏损时自动降级为立即清仓**
5. **保护基线**：空仓观察/等待首仓阶段 止盈/移动止盈/止损 3 开关强制开（输出 false 无效，别反复输出）；`预测置信度 < 0.6` 整轮被弃用并防守兜底。
6. **网格管理期硬约束**：基础底仓不可卖出（`是否允许卖出基础底仓` 被忽略并留痕）。

## 一、开首仓场景（空仓观察 → 等待首仓）

**盘面判断（先取数）**：价格距一级支撑的距离、近 24h/3 月分位、支撑是否被验证（≥2 次触碰未破）、风险收益比（支撑 vs 压力距离比 ≥ 1.8 才值得动手）。

| 意图 | 阶段 | 操作 | 主要参数 |
|:--|:--|:--|:--|
| 试探仓（信号一般，等确认） | 等待首仓 | 择机 | `用户或者智能体的备注=开仓意图（必填）`、`是否允许网格主动开仓=true`、`建议首仓占比=0.1~0.15`、`首仓价格区间=[支撑下沿, 支撑上沿]` + `是否限制首仓价格区间=true`、`禁止追高价格=区间上沿` + `是否禁止追高=true`、**同时预配网格**：间距/数量/格盈（首仓建立后按此运行） |
| 笃定仓（支撑确认 + 趋势同向 + 分位低） | 等待首仓 | 立即 | `用户或者智能体的备注=开仓意图（必填）`、`建议首仓占比=0.3~0.5`（当前价须在首仓区间内，否则立即=不下单）、`是否允许网格主动开仓` 无需输出（立即=系统配对开） |
| 事件前 / 分位高位 / 风险收益不足 | 空仓观察 | 禁止 | 全参数默认即可（空仓观察阶段参数仅存档，重点是"不下单+主动开仓关"） |

**要点**
- 择机路径 = 回踩到区间内由 CCI 自动开首仓；想让 AI 精确挑时刻才用立即。
- 网格参数在空仓期就是"预配置"，不输出=首仓建立后走模板默认（间距 0.03/数量 10/格盈 0.03）。
- 美股：确认 `us_stock_trading_hours_only` 语义（仅盘中执行）；盘前信号盘后才开仓，首仓区间要按盘前跳空重算。

## 二、持仓亏损场景（首仓建立中 / 网格管理期，浮亏未及止损线）

**盘面判断**：`cta_strategy_get_status`（持仓均价 vs 开仓价、`已有网格仓数量`=已触发几格、当前网格参数）；`get_history_bars`（一级支撑还有效吗、价格到哪个 band 了）；`get_positions`（实际浮亏 %）。

**两条路线，二选一，别混着来**：

**A. 网格兜底（震荡市 / 支撑有效 / 想摊低成本）**
| 意图 | 主要参数（每轮重复输出） |
|:--|:--|
| 多格逐步兜底 | `是否允许亏损时网格加仓=true`、`网格数量=10~20`、`网格间距=0.02~0.03`（币 0.03~0.05）、`网格止盈=0.015~0.03`、`止损幅度=间距×数量×0.6`（公式，别超过）、`是否允许止损=true` |
| 少格笃定反转 | `是否允许亏损时网格加仓=true`、`网格数量=1~3`、`网格间距=0.05~0.10`（直接踩到大级别支撑档）、`网格止盈=0.04~0.08`、`止损幅度=0.05~0.10`（错了马上砍，不等兜底） |

**B. 不接刀（疑似单边 / 支撑已破 / 大盘走坏）**
| 意图 | 主要参数 |
|:--|:--|
| 只收紧止损 | `是否允许亏损时网格加仓=false`、`止损幅度=0.03~0.05` 收紧、或 `是否允许ATR动态止损=true` + `止盈止损用ATR倍数=8~15` |
| 防浮盈转亏 | `是否允许移动止盈=true` + `移动止盈启动幅度=0.03` + `移动止盈回撤幅度=0.01~0.02` |

**要点**
- "笃定"必须有盘面证据（密集成交区 + RSI 背离 + CCI 超卖 + 分位 < 0.2 至少占两条）；说不出证据就用多格兜底或 B。
- 已触发网格越多，剩余弹药越少——`cta_strategy_get_status` 的"已有网格仓数量" ÷ 网格数量 = 已消耗比例，>70% 时优先谈"能不能走"而不是"再加一格"。

## 三、持仓盈利场景（网格管理期 / 利润收割期，浮盈中）

**盘面判断**：趋势是否延续（分位、均线排列）；距离压力位还有多少；是否事件窗口。

| 意图 | 阶段 | 主要参数 |
|:--|:--|:--|
| 顺势加（首仓后趋势确认） | 首仓建立中 | `操作=择机` + `是否允许盈利时网格加仓=true`（该阶段由你显式决策；禁止=强制关） |
| 网格收割（震荡上行，每格落袋） | 网格管理期 | `网格止盈=0.02~0.03` + `是否允许网格减仓=true`（反弹到格盈即卖该格，保留基础仓） |
| 趋势保护（防回吐） | 网格管理期/利润收割期 | `是否允许移动止盈=true` + `移动止盈启动幅度=0.03~0.05` + `移动止盈回撤幅度=0.01~0.02`（越接近压力越收紧） |
| 基础仓分批出 | 仅利润收割期 | `是否允许卖出基础底仓=true` + `基础底仓分批出货比例=0.33~0.5`（别一次 1.0，除非要全走） |
| 全止盈（不玩了） | 利润收割期 | 见 §四 |

**要点**
- 网格管理期"操作"没有下单动作（立即/择机/禁止=无动作），该阶段只调参数。
- 盈利加仓与亏损加仓**不要同时全开**——同向双开等于放弃风控意图，选一个方向。

## 四、获利离场场景（利润收割期 → 清仓）

| 意图 | 阶段 | 操作 | 主要参数 |
|:--|:--|:--|:--|
| 立即全清（趋势到位 / 到压力 / 事件前） | 利润收割期 | **立即** | 所有加仓开关（亏损/盈利/主动开仓）=false——防止平仓途中被 CCI 加仓 |
| CCI 择机分批出货 | 利润收割期 | 择机 | 不下单，按网格规则出货；配 `是否允许网格减仓=true` + `网格止盈` 定出货档 |
| 事件前分批撤 | 风险退出期 | 择机 | `基础底仓分批出货比例=0.33/0.5`（盈利时=CCI 择机分批；亏损时自动降级立即清仓） |
| 撤单保护 | 同上 | — | `是否允许移动止盈=true` + 回撤幅度 0.01（最后防线） |

**要点**：风险退出期代码**强制开** 卖基础底仓 + 网格减仓（AI 给 false 也无效，会留痕）——进这个阶段就是"出货模式"，别再开任何加仓开关。

## 五、亏损离场场景（结构破坏 / 接近止损线）

**关键**：网格管理期"立即"无动作，**亏损离场要走风险退出期或止损参数**，两条路：

| 意图 | 阶段 | 操作 | 主要参数 |
|:--|:--|:--|:--|
| 立即砍（支撑全破 / 大盘崩 / 逻辑失效） | 风险退出期 | **立即**（或禁止，均=立即清仓） | 无（阶段即指令；清仓后系统回空仓观察） |
| 让止损执行（不人工干预） | 维持现阶段 | — | `止损幅度=0.02~0.03` 收紧 或 `是否允许ATR动态止损=true` + `止盈止损用ATR倍数=8~12` |
| 空头持仓防追空（价格弹回） | 维持现阶段 | — | `是否禁止追高=true` + `禁止追高价格=红线`（空头语义=低于此价禁止开/加仓） |
| 事件窗口防守 | 维持现阶段 | 禁止 | 不下单 + 加仓开关强制关（等待首仓/首仓建立中语义），等事件落地再评估 |

**要点**：清仓成功后策略回空仓观察，3 保护开关自动强制开；别在清仓同轮还输出"加仓=true"。

## 六、风险退出场景（风险退出期：系统性风险 / 策略失效 / 重大事件）

**触发判断**：大盘/板块系统性下跌（`大盘与板块和资金流向分析` 技能）、个股重大事件（财报/FOMC/CPI/政策）、策略连续止损（`cta_strategy_get_all_reason` + `get_trades` 看近期止损次数 ≥ 3 且原因重复）。

| 意图 | 操作 | 主要参数 |
|:--|:--|:--|
| 全撤（系统风险，别分批了） | 立即 | 无——立即/禁止都是立即清仓 |
| 盈利仓位分批撤 | 择机 | `基础底仓分批出货比例=0.33/0.5`；盈利=CCI 择机分批出货，**亏损自动降级立即清仓** |
| 撤后空仓防守 | （撤完）空仓观察 + 禁止 | `是否允许网格主动开仓=false`；重新开仓需重新走 §一 的完整判断 |

**要点**：风险退出期 卖基础底仓 + 网格减仓 被代码强制开（留痕）；"事件前撤退、事件后重建"是标准循环——事件落地前别重新进等待首仓。

## 七、网格两大范式（核心手法）

| | A 多格逐步兜底 | B 少格笃定反转 |
|:--|:--|:--|
| 信念 | "会跌到这一带，接住它" | "到这儿必反转，重仓接" |
| 盘面前提 | 区间清晰、支撑强、分位中低 | 大级别密集成交区 + RSI 背离 + CCI<-100/超卖 + 分位<0.2（≥2 条证据） |
| 网格数量 | 10~20 | 1~3 |
| 网格间距 | 0.015~0.03（币 0.03~0.05） | 0.05~0.10（一步踩到关键位） |
| 网格止盈 | 0.015~0.03（每格赚小钱） | 0.04~0.08（每格赚大钱） |
| 首仓占比 | 0.1~0.15（省弹药） | 0.2~0.3（反转确认后敢上量） |
| 止损幅度 | 公式值（间距×数量×0.6，通常 0.10~0.18）——**必须能接受** | 0.05~0.10（错了立刻砍） |
| 每格资金 | 总资金×(1−占比)÷15 ≈ 5~6% | 总资金×(1−占比)÷2 ≈ 40%（大） |
| 失败模式 | 单边下跌把弹药耗光（用止损幅度封顶） | 判断错了亏得重但只一次（快速证伪） |

**第三选项：不用网格**——趋势单：所有网格加仓开关=false + 建议首仓占比 + ATR 动态止损止盈（倍数 8~15）+ 移动止盈。适合单边市；震荡市慎用（容易被洗）。

**切换纪律**：A/B/不用网格 三种手法**一次只选一种**，且切换要在"理由"里写清为什么换（上一轮是 A 这轮改 B，必须在理由中说明盘面变化）。

## 九、vnpy_mcp 取数速查（实盘盘面推断）

| 想知道什么 | 工具 | 看什么 |
|:--|:--|:--|
| 策略现在什么状态 | `cta_strategy_get_status` | 策略阶段/持仓/持仓均价/开仓价/已有网格仓数量/当前全部参数 |
| 这笔持仓怎么来的、参数怎么变的 | `cta_strategy_get_all_reason` | 开仓时 AI 理由 + 参数修改历史（source：manual/mcp/ai/system/reset） |
| 真实持仓与盈亏、可用资金 | `get_positions` + `get_accounts` | 浮亏 %（对照止损幅度）、弹药是否够剩余网格 |
| 支撑/压力/分位/结构 | `get_history_bars`（多周期）+ `get_tick` | 一级支撑验证次数、近 24h/3 月分位、ATR 量级（对照 ATR 倍数） |
| 最近成交 | `get_trades` / `cta_strategy_get_trade_history` | 已触发几格、止损次数（≥3 次同因→风险退出评估） |
| 全策略概览 | `cta_strategies_get_all` | 哪个策略最危险、资金总占用 |

**取数 → 决策路径**：`get_status`（阶段+网格现状）→ `get_positions/accounts`（盈亏+弹药）→ `get_history_bars/tick`（结构+分位）→ 对照 §七 选范式 → 按 §零 纪律输出。

**两个落地通道**：
- 内部 AI 分析轮：按 00-Router §五 的 42 字段 JSON 输出（单轮指令语义，持续参数每轮重复，含开仓意图备注）；
- 外部智能体/人工：`cta_strategy_set_parameters`（英文参数名，type/min/max 校验，source=mcp 持久保留，不被单轮复位清掉）——适合设"基线型"参数（如网格间距、ATR 倍数），不适合每轮变的"指令型"参数。
