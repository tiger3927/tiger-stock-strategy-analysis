# 08 — 策略行为规则与坑点速查

> 用参数驾驭策略时必须理解的行为规则：参数复位语义、调仓门控、价格锚点、量参数效应、策略形态。

---

## 一、行为规则与坑点

### 1. 策略阶段由具体策略定义

`策略阶段`（如：空仓观察/等待首仓/首仓建立中等）由具体策略代码定义，基类不预设任何阶段枚举。阅读状态上报中的阶段字段时，不同策略的阶段划分可能不同。

### 2. 每次 AI 结果应用前会分层复位参数（安全阀）

防止上一轮的开关/数值残留导致意外交易。它是**分层复位**（语义详见 04）：AI 可控参数恢复默认，用户/MCP 刻意设置的参数作为基线保留。
**对智能体的含义：** 想让某个参数持续生效，要么每轮 JSON 都携带，要么由用户/MCP 设置一次（后续不会被复位清掉）。

### 3. 状态上报是快照，不是实时流

`_build_status_dict()` 输出的是调用时刻的快照。智能体应基于快照做分析，不考虑调用期间的微小价格变化。

### 4. AI 订单审核由基类自动完成

`enable_openclaw_confirm_target_pos=True`（人工设定）时，每次调仓前自动提交 AI 审核，智能体返回 `{"decision": "同意|拒绝", "approved_target_pos": 0.0, "reason": "..."}`，同意后才执行（协议见 04 第五节）。

### 5. `target_pos == self.pos` 是网格加减仓的闸门

当有主要调仓正在进行时（`target_pos ≠ pos`），网格加减仓自动暂停。智能体通过 JSON/MCP 设定的 target_pos 优先级高于自动化网格。

### 6. `first_open_price` 是网格的基准锚点

网格间距以此价计算，而非当前价。`first_open_price` 在首笔成交时记录，后续加仓不会更改此值——预估网格触发价格时要用它，不要用当前价。

### 7. `volume_change_with_v=True` 的双刃剑效应

盈利时每次加减仓量变大（加速效应），亏损时每次加减仓量变小（减速效应）。若希望每笔加减仓量固定，应建议用户将此参数设为 False（人工参数，智能体不可设置）。

## 二、通过参数组合实现的策略形态

> 基类封装了交易执行的全链路（订单引擎、止盈止损、网格加减仓、风控链、交易量计算、状态上报），
> 信号来源（何时调仓、调多少）由具体策略代码负责——**参数改变不了信号，但参数决定了每次调仓"怎么执行、执行多少、如何保护"**。
>
> 通过参数组合，同一套策略可变为多种形态（智能体驾驭策略的主要手段）：

| 策略变体 | 关键参数 |
|:--|:--|
| **一次性建仓（不补仓）** | `first_part=1.0` |
| **纯网格防守** | 所有 `enable_martin_*` = False |
| **纯趋势跟踪** | 所有 `enable_martin_*` = False, ATR 止损止盈 + 移动止盈 |
| **盈利加仓进攻（顺趋势追仓）** | `enable_martin_add_profit=True` + 移动止盈 |
| **AI 全托管** | `enable_openclaw_analysis=True`, `enable_openclaw_confirm_target_pos=True` |
| **完全自主** | `enable_openclaw_analysis=False` |
