## 〇、本套文档的用途与视角（⚠️ 必须首先理解）

> 本套文档**唯一视角**：写给 AI 智能体的**通过参数设置驾驭策略代码**的手册。
>
> - **用途**：让智能体理解策略机制后，通过设置参数实现交易意图（意图 → 参数 JSON / 调仓指令）；
> - **只写**"设了参数后会发生什么"：触发条件、量公式、风控拦截、参数联动；
> - **不写**写策略代码/扩展策略的内容（写子类、重写方法等开发者视角不在本套文档范围内）；
> - 策略代码内部工艺（防抖/节流、冷静期、状态发布实现等）不写入，查不到属正常，不代表文档缺失；
> - 参数按"可改性"分级（AI / MCP / 人工 / 人工作业层控制），AI JSON 只能携带 AI 可控参数，键名用标准名（代码 name_cn）。

## 一、基类与信号层的职责边界（⚠️ 必须首先理解）

```
┌─────────────────────────────────────────────────────────────┐
│                 基类（TigerGridTemplate）提供                │
│  交易执行的全链路基础设施——全部可通过参数驾驭：               │
│                                                             │
│  ✅ 订单执行引擎    set_target_pos()→trade()→send_new_order  │
│  ✅ 止盈止损系统    固定比例 + ATR动态 + 移动止盈（三系统并行）│
│  ✅ 网格加减仓机制   四段逻辑：减仓→亏损加仓→盈利加仓→主动开仓  │
│  ✅ AI 调用框架     API 通信调度（发请求、收响应、回调分发）  │
│  ✅ 下单风控链      冷却期/超时/滑点/价格保护/资金上限         │
│  ✅ 交易量计算      get_fixed_volume/get_martin_add_volume    │
│  ✅ 状态上报        _build_status_dict()                      │
│  ✅ 参数安全机制    reset_ai_strategy_params()                 │
├─────────────────────────────────────────────────────────────┤
│              基类不提供（信号来源，参数改变不了它）            │
│                                                             │
│  ❓ 开仓信号判断 —— 基类不判断任何信号，由具体策略代码决定    │
│  ❓ 何时调仓     —— 策略代码自己决定何时调用 set_target_pos() │
│  ❓ 策略阶段     —— 基类不预设任何阶段枚举                   │
└─────────────────────────────────────────────────────────────┘
```

> **核心：基类解决"怎么执行"，策略代码解决"用什么信号、什么时候执行、执行多少"。
> 参数组合可把基类配置成多种策略形态（见本文第五节）。**

## 四、快速架构概览

```
信号层（策略代码 / AI 分析）
  ├── 信号判断（方向、仓位、时机）
  └── 调用 set_target_pos(target_pos)
        │
        ▼
基类（执行层）
  ├── 风控链拦截（时段/冷却/价格/资金）
  ├── do_set_target_pos() 记录目标
  ├── trade() 订单引擎（每tick/bar驱动）
  ├── send_new_order() 发送限价单
  ├── on_order() / on_trade() 确认成交
  ├── profit_loss_stop_action() 每tick止盈止损检查
  └── martin_add_sub() 每bar网格加减仓
```

> 注意：若 `enable_openclaw_confirm_target_pos=True`（人工设定），调仓在 `set_target_pos()` 阶段先提交 AI 审核，同意后才执行，由基类自动完成，智能体无需额外操作。

## 五、基类的灵活配置变体

通过参数组合，基类可被配置为多种策略形态（无需修改代码）：

| 策略变体 | 关键参数设置 |
|:--|:--|
| **一次性建仓（不用补仓）** | `first_part=1.0`（首仓动用全部资金，网格加仓量自然为 0） |
| **纯网格防守（不加仓不操作）** | 所有 `enable_martin_*` = False，仅止盈止损运行 |
| **纯趋势跟踪（不网格）** | 所有 `enable_martin_*` = False，ATR 止损止盈 + 移动止盈 |
| **盈利加仓进攻（顺趋势追仓）** | `enable_martin_add_profit=True` + 移动止盈 |
| **AI 全托管** | `enable_openclaw_analysis=True`，`enable_openclaw_confirm_target_pos=True` |
| **完全自主（不依赖 AI）** | `enable_openclaw_analysis=False`，完全依靠策略内置信号 |
| **变盘防御（趋势反转时）** | `enable_martin_add_loss=False`，`enable_martin_sub=True`（`loss_close_need_manual` 需为 False，人工设置） |

> 详参见 [`09_scenarios.md`](09_scenarios.md) 各场景完整配置。
