# 加密货币做空选择 — 提前发现的做空逻辑

> 本文档是 [00_index.md](00_index.md) 的**做空分支**执行细则。
>
> **加密做空与美股做空的三个本质差异（先读）**：
> 1. **工具是永续合约**（不是借券）：无需借券费，但有**资金费率**成本；空单被强平后价格上限无限，风险不对称
> 2. **轧空是头号风险**：低流通 + 高控盘 + 费率极端负 → 一次逼空可以打掉数月利润
> 3. **供给冲击是确定的**：解锁日历是全网公开的，这让加密做空比美股更依赖**事件**而非估值

---

## 一、投资目标与风格定义

**风格：过热反噬 + 供给冲击（Overheat & Supply Shock）**

寻找满足以下条件的做空标的：

1. **板块过热或叙事衰竭**：7 日涨幅 > 40%、情绪极端、讨论度见顶
2. **可预期的供给冲击**：未来 30 天大额解锁、团队/国库转入交易所
3. **杠杆拥挤**：资金费率 > 0.1%/8h、OI 处于历史高分位
4. **技术面破位确认**：跌破关键均线/前低且反抽失败
5. **但轧空风险可控**：流通市值不太小、OI 未极端集中

**不做的三件事**：
- 不做空 **BTC/ETH**（流动性太深、大资金托底、宏观叙事支持）
- 不做空**流通市值 < $300M 且费率极端负**的标的（轧空高危）
- 不做空**有明确强催化**（即将上币、ETF、有利裁决）的标的

## 二、宏观与板块分析

复用 `gate`，做空友好的环境：

| BTC 均线结构 | 跌破 MA50 / MA200 | 站稳 MA20 以上 |
| BTC.D | 快速上行（山寨抽血） | 下降（山寨季） |

## 三、初步筛选（从宽到窄）

### 3.1 板块过热与叙事泡沫信号

| 检查项 | 做空信号 |
|--------|---------|
| 短期涨幅 | 7 日 > 40%，或 30 日 > 100% |
| 情绪 | Crypto F&G > 75（极度贪婪）且标的滞涨 |
| 叙事质量 | 无真实需求（无 TVL / 无收入 / 无使用量） |
| 价格结构 | 新高后放量长上影、连续 2 日收阴 |

### 3.2 代币经济学恶化信号（加密版"基本面恶化"）

| 检查项 | 做空信号 |
|--------|---------|
| **解锁（最重要）** | 未来 30 天**悬崖解锁** > 流通量 1%；团队/VC 成本极低 |
| 通胀率 | 年化 > 15% 且无销毁机制 |
| 国库/基金会动向 | 大额转入交易所（`web_fetch` 区块浏览器 / Arkham 类页面；`web_search` 仅作入口） |
| 质押解锁 | 质押率快速下降（抛压在释放） |

### 3.3 资金面过热信号

| 检查项 | 做空信号 |
|--------|---------|
| 资金费率 | 持续 > 0.1%/8h（多头付费，做空收钱） |
| OI | 历史高分位且价格滞涨（> 52 周 90 分位） |
| 交易所净流入 | 连续 3 日 > 1 万 BTC/日量级（大额转入待售） |
| 现货-合约基差 | 合约大幅升水（情绪过热） |

### 3.4 链上与协议恶化信号

| 检查项 | 做空信号 |
|--------|---------|
| TVL | 连续 2 周下降 > 10% |
| 活跃地址 | 持续下降（用户流失） |
| 协议收入 | 连续下降 |
| 安全事件 | 被攻击 / 暂停提币 / 团队跑路传闻（**须核实**，不基于传闻下单） |

## 四、技术面过滤

### 4.1 趋势形态确认

- **空头结构**：价格 < MA20 且 MA20 拐头向下（强空头：< MA50 < MA20）
- **反抽失败**：反弹触及 MA20/前低后放量回落
- **不追跌**：已从高点下跌 > 40% 且无反弹 → 等反抽再空（避免空在反弹起点）

### 4.2 经典看跌形态

| 形态 | 说明 |
|------|------|
| 双顶 / 头肩顶 | 右肩量能萎缩 + 跌破颈线 |
| 跌破关键支撑后反抽失败 | 最优做空点 |
| 上升楔形下破 | 配合放量 |
| 均线死叉（MA20 下穿 MA50） | 趋势转折初段 |
| 高位放量长上影 / 吞没 | 单日反转信号（需次日确认） |

### 4.3 动量与超买信号

- **超买确认**：1D RSI > 80、4H CCI > 200 → **等拐头**再空（不空在最高点）
- **顶背离**：价格新高但 RSI/CCI 未新高 → 做空加分项
- **量价背离**：价格新高而成交量递减 → 做空加分项

## 五、深度尽调与下跌催化剂验证

### 5.1 供给冲击分析（加密独有的做空主轴）

| 要素 | 判断 |
|------|------|
| 解锁类型 | **悬崖（Cliff）> 线性（Linear）**：悬崖冲击集中 |
| 解锁对象 | 团队 / 早期 VC（成本极低、抛售意愿强）> 生态基金 / 国库 |
| 解锁规模 | > 流通量 1% = 显著；> 3% = 强信号 |
| 时间窗口 | 解锁日前 1-3 天常见的"抢跑抛售"是入场窗口；**解锁落地后若价格不跌 → 供给已被消化，立即离场**（利空出尽） |

### 5.2 下跌催化剂类型

| 类型 | 力度 | 备注 |
|------|------|------|
| 大额解锁（悬崖） | 强（确定性最高） | 日期公开、可提前布局 |
| 交易所**下币公告** | 极强（短期） | 通常伴随流动性枯竭，做空需注意能否平仓 |
| SEC/CFTC 不利裁决 | 强（品种级） | 核查裁决日历 |
| 协议被攻击 / 提币暂停 | 极强 | 无法预判，**不做前置布局**，只在确认后评估 |
| 代币通胀/通胀治理变更 | 中 | 需核对是否已 price in |
| 生态项目暴雷 / 核心开发者流失 | 中 | `web_fetch` 项目官网 / 公告页（`web_search` 仅作入口） |
| 宏观：BTC 跌破关键位 | 中（系统性） | 山寨跌幅放大 1.5-2 倍 |

### 5.3 团队与生态（做空视角）

- 是否依赖单一叙事/单一大户
- 国库地址是否有大额转出记录
- 治理是否被单一实体控制（可能直接砸盘）
- 是否存在未公开的解锁/增发条款

### 5.4 情绪与共识（做空视角）

- Crypto F&G > 80 + 标的滞涨 = 顶部风险
- 讨论度极端（KOL 集中喊单）→ 晚期信号
- 合约 OI 与持仓集中度：**集中度过高 = 轧空风险高**（见 §6.1 轧空评估）

## 六、综合判断与入场时机

### 6.1 评分卡（做空版）

| 维度 | 权重 | 5 分 | 3 分 | 1 分 |
|------|------|------|------|------|
| 板块过热 / 叙事衰竭 | 20% | 7 日 > 50% 且滞涨 + 轮动晚期 | 中度过热 | 无过热迹象 |
| 解锁抛压 | 15% |  cliffs > 3% 流通量、团队持有 | 1-3% | 无解锁 |
| 资金费率与杠杆 | 15% | 费率 > 0.15%/8h + OI 90 分位 | 0.05-0.1% | 费率正常/负 |
| 技术面破位 | 15% | 破位 + 反抽失败 + 死叉 | 均线下方震荡 | 多头结构完好 |
| 链上与协议恶化 | 15% | TVL 连续下降 > 10% | 走平 | 增长 |
| 下跌催化剂 | 20% | 下币/裁决/大额解锁（未 price in） | 一般利空 | 无或已兑现 |

**总分 = Σ(维度分 × 权重)**；执行阈值见 00_index（默认 4.0；板块过热特批情形 4.5）。

### 6.2 做空双闸（不过闸不得输出为可执行做空）

#### 闸一：轧空风险评估

| 风险等级 | 判定条件（满足 2 条即升一级） |
|---------|------------------------------|
| **高（禁止做空）** | 流通市值 < $300M；合约 OI / 流通市值 > 15%；费率极端负（< -0.05%/8h）且 OI 高；近 7 日有上币/强催化 |
| 中 | 流通市值 $300M-$1B；OI/流通市值 8-15% |
| 低 | 流通市值 > $1B 且 OI/流通市值 < 8% |

> **输出要求**：`squeeze_risk` 为必填字段；评估为"高"的标的**一律降级为观察清单**，不得出现在可执行列表。

#### 闸二：做空成本核算

- 资金费率折算：`日成本% = 费率(每8h) × 3`
- 若日成本 > 目标跌幅的 1/3 → 降级为观察（时间成本过高）
- 正费率时做空**收钱**（成本为负），需在 `入场计划.资金费率成本` 中说明

### 6.3 入场时机选择

| 场景 | 入场方式 |
|------|---------|
| 破位反抽失败 | 反抽至 MA20/前低时进 1/3 底仓，再次破位加仓 |
| 解锁前抢跑 | 解锁前 2-3 天入场，**解锁落地若未跌即离场** |
| 费率极端 | 等费率从极端高位拐头（避免站在拥挤的反面） |
| 系统性下跌 | 只做空跌幅放大效应最强的高 beta 山寨，仓位减半 |

## 七、仓位管理与风险控制

### 7.1 仓位规则

- 单标的仓位上限：**5-8%**（默认 6%）；小市值标的 3-5%
- 同板块做空合计 ≤ 15%（板块内相关性高）
- 总做空仓位 ≤ 20%（加密系统性反弹往往同步）
- 杠杆：有效杠杆 ≤ 1.5 倍（保证金占用按名义额），**必须留足维持保证金**
- **禁止**用全仓模式做空小市值标的（强制平仓风险）

### 7.2 止损策略

| 方式 | 规则 |
|------|------|
| 结构止损 | 站回 MA20 上方并收线确认，或突破前高 |
| 波动止损 | 入场价 + max(6%, ATR(14) × 2.5) |
| 轧空止损 | 单日涨幅 > 15% 且 OI 骤增 → 立即减半（可能逼空启动） |
| 时间止损 | 5-8 个交易日内未按预期方向运行 → 减半（费率成本累积） |
| 系统性止损 | BTC 单日 > 8% 反弹或全市场空头爆仓 > $3 亿 → 全部降仓 |

### 7.3 目标价设定

- 第一目标：前低 / 下方支撑区（约 15-25% 空间）
- 第二目标：更下方结构位或「上涨启动前的整理区」
- **分批止盈**：第一目标减 1/2（加密反弹快），第二目标减 1/3，剩余跌破 MA20 全部离场
- 移动止盈：浮盈 > 25% 后，回撤 10% 触发

### 7.4 做空特有风险（加密版）

| 风险 | 说明 | 对策 |
|------|------|------|
| **轧空（头号风险）** | 低流通 + 高控盘，一次逼空可打掉数月利润 | 走 §6.2 闸一，高风险一律不做 |
| **无限上行风险** | 永续合约空单理论上亏损无上限（美股做空最大亏损有限） | 严格执行止损；禁止扛单 |
| 资金费率成本 | 负费率时空头持续付费；持有多日成本累积 | 走 §6.2 闸二，折算日成本 |
| 流动性枯竭 | 下币/极端行情时深度消失，**无法平仓**或巨大滑点 | 不做市值过小标的；避开下币公告标的 |
| 强制平仓 | 保证金不足被系统强平（时间不可控） | 用逐仓 + 保证金率留 > 50% 缓冲 |
| 交易所风险 | CEX 宕机/提币暂停/偿付问题 | 仓位分散、控制单所敞口 |
| 监管突变 | 有利裁决/ETF 通过 = 逼空催化 | 核查裁决与 ETF 日历，事件前减仓 |

## 九、平仓纪律

出现以下任一情况必须平仓（**加密做空的时间成本高，不恋战**）：

1. **止损触发**（结构 / 波动 / 轧空 / 系统性任一）
2. **利空兑现**：解锁落地后价格未跌、下币公告后价格企稳 → 立即离场
3. **出现强催化**：上币、ETF、有利裁决消息 → 立即离场（逼空风险）
4. **费率转负且加剧**：持空成本快速上升
5. **BTC 转强**：BTC 站回 MA50 且 BTC.D 下降（山寨反弹环境）
6. **流动性恶化**：盘口深度骤降、无法在目标价附近平仓 → 优先平仓保命
