# 加密货币做多选择 — 提前发现的做多逻辑

> 本文档是 [00_index.md](00_index.md) 的**做多分支**执行细则。美股做多用 PE/PEG 等估值指标，加密没有财报，做多逻辑建立在**叙事成长 + 代币经济学 + 资金面**三支柱上。

---

## 一、投资目标与风格定义

**风格：叙事成长型（Narrative Growth）**

寻找"下一个被资金关注、但尚未拥挤"的板块中的龙头标的，要求：

1. **叙事有真实需求支撑**（不是纯喊单）：板块有链上数据、TVL、真实使用量或明确的宏观/资金通道叙事（ETF、RWA、监管明朗化）
2. **代币经济学不拖后腿**：通胀可控、近期无大额解锁
3. **流动性足够**：能进能出，滑点与最小下单量不构成障碍
4. **未过度拥挤**：资金费率中性偏低、`pct_52w` 不在极值区

**不做的三件事**：
- 不追 **7 日涨幅 > 50%** 的标的（晚期特征，赔率极差）
- 不碰**上线 < 30 天**或**未来 30 天有大额解锁**的标的
- 不碰**不在可交易清单**内的标的（无法执行 = 无意义）

## 二、宏观与板块分析

### 2.1 宏观环境判断

复用 `gate`（大盘报告或价格结构降级闸门），重点看：

| 指标 | 做多友好 | 做多不利 |
|------|---------|---------|
| BTC 均线结构 | 站上 MA20 且 MA20>MA50 | 跌破 MA50 |
| BTC.D | 走平或下降（资金扩散） | 快速上行（山寨失血） |
| ETH/BTC | 上行（风险偏好扩散） | 下行（资金回流 BTC） |
| 稳定币市值 | 扩张（增量弹药） | 连续下降 |
| 风险偏好（VIX/HYG_LQD，来自 us-all） | VIX 下行、信用利差收窄 | VIX 飙升、利差走阔 |

### 2.2 板块轮动滞后机会（重点）

**核心思路**：找"已经启动但还没被充分定价"的板块，而不是找"最热"的板块。

| 信号 | 含义 | 操作 |
|------|------|------|
| 板块 20 日跑赢 BTC 5-15pct，但 `pct_52w` < 70 | 启动初期，空间尚存 | **首选做多窗口** |
| 板块 20 日跑赢 BTC > 25pct 且资金费率转正 | 已拥挤 | 降级观察，不追 |
| 板块 20 日跑输 BTC > 10pct，但链上/TVL 未恶化 | 滞后补涨候选 | 等资金费率转正 + 技术面止跌再进 |
| 板块 TVL 周增 > 5% 且价格未跟涨 | 基本面领先价格 | 优先关注（背离修复） |

### 2.3 板块轮动预测（与 00_index Step 1.5 一致）

按 00_index §1.5.3 的矩阵判定下一个轮入板块，输出到 JSON 的 `下一轮动预测`。若多个板块同时满足，按以下优先级：

```text
BTC/ETH 同涨（大市值行情）  → 做多 BTC/ETH 本身（不追山寨）
ETH/BTC 上行 + BTC.D 下降   → L1 龙头 → DeFi
某板块单独领涨 + OI 上升     → 该板块龙头（注意杠杆拥挤）
Meme 集体暴涨               → 反向信号，转防御（做多 BTC 或空仓）
```

## 三、初步筛选（从宽到窄）

### 3.1 代币经济学信号（等于美股的"价值低估"位）

| 检查项 | 好信号 | 坏信号 |
|--------|--------|--------|
| 解锁曲线 | 未来 30 天无解锁，或解锁量 < 流通量 0.3% | 未来 30 天解锁 > 流通量 1% |
| 通胀率 | < 5%/年或有销毁/回购 | > 15%/年且无销毁 |
| 流通比例 | > 60% | < 20%（且解锁集中） |
| 供应机制 | 有上限 / 有销毁（如 EIP-1559 类） | 无限增发无销毁 |

### 3.2 叙事成长信号（等于美股的"增长潜力"位）

| 检查项 | 好信号 |
|--------|--------|
| 赛道 | 处于资金关注度上升的赛道（AI/RWA/DePIN/新 L1…） |
| 生态数据 | TVL 周增 > 5% / 活跃地址回升 / 协议收入增长 |
| 事件 | 明确的升级、上线、合作、ETF 通道，且**未被价格充分反映** |
| 竞争位置 | 板块内前 3（叙事扩散时资金优先买龙头） |

### 3.3 资金面信号

| 检查项 | 好信号 | 坏信号 |
|--------|--------|--------|
| 资金费率 | 0 ~ +0.03%/8h（正常） | > 0.1%/8h（过度拥挤） |
| 持仓量 OI | 温和上升（跟随价格） | OI 创历史新高而价格滞涨 |
| 交易所净流入 | 净流出（提币囤币） | 连续 3 日大额净流入 |
| ETF 资金（仅 BTC/ETH） | 连续净流入 | 连续净流出 |

### 3.4 流动性稳健信号

| 检查项 | 门槛（默认，可按风险偏好调整） |
|--------|------|
| 24h 成交额 | ≥ $20M（小市值高弹性标的可放宽至 $5M，但仓位减半） |
| 20 日均量分位 | 不低于 52 周 20 分位（避免长期缩量） |
| 盘口深度 | 目标建仓量对应滑点 < 0.5% |
| 可交易性 | 必须命中 `get_all_contracts` |

## 四、技术面过滤

### 4.1 趋势形态确认

- **多头结构**：价格 > MA20 > MA50，且 MA20 向上
- **健康回踩**：回踩 MA20 缩量（量 < 20 日均量），站回后放量
- **不追高**：`pct_52w` > 90 且当日涨幅 > 8% → 等回踩

### 4.2 经典看涨形态

| 形态 | 说明 | 关注点 |
|------|------|--------|
| 突破回踩（Breakout-Retest） | 突破前高/整理区上沿后回踩不破 | 最优入场点 |
| 下降楔形上破 | 高点降低、低点抬升后向上突破 | 配合放量 |
| 箱体上沿突破 | 长期横盘后放量突破 | 需成交量确认 |
| 均线金叉（MA20 上穿 MA50） | 趋势转折初段 | 配合 BTC.D 下降更佳 |

### 4.3 动量与超卖信号

- **超买区**：1D RSI > 80 或 4H CCI > 200 → **不新开仓**（可持已有仓位）
- **超卖反弹**：4H CCI < -200 且价格未破 MA50 → 反弹候选（非趋势起点）
- **量价背离**：价格新高但 24h 成交量递减 → 警惕，降一档评分

> 加密波动大：`pct_52w`、RSI、CCI 的阈值比美股更宽，但**不追高**的纪律更严。

## 五、深度尽调与催化剂验证

### 5.1 代币经济学质量分析

- 解锁日历：**团队/VC 的悬崖解锁**（Cliff）比线性解锁危险得多，查清解锁对象
- 通胀与销毁：核对当前实际通胀率（不是白皮书数字），以及销毁是否真实执行
- 国库/基金会持仓：大额国库地址是否在近期转入交易所（`web_fetch` 区块浏览器 / Arkham 类页面；`web_search` 仅作入口）

### 5.2 催化剂类型

| 类型 | 力度 | 注意 |
|------|------|------|
| 交易所上币（主流 CEX） | 强（短期） | 常"见光死"，需评估已被预期的程度 |
| 协议升级 / 硬分叉 | 中强 | 有明确日期最好 |
| ETF 通过 / 机构增持（BTC/ETH 为主） | 强（中期） | 传统资金通道 |
| 监管明朗化（有利裁决） | 强 | 系统性利好 |
| 生态大会 / 合作公告 | 弱-中 | 易被过度营销 |
| 空投/分叉预期 | 中 | 关注是否已 price in |

### 5.3 团队与生态护城河（加密版）

- 开发活跃度：GitHub 提交、核心开发者是否流失
- 生态集中度：是否只依赖单一应用/单一叙事
- 竞争位次：同类协议中 TVL/收入排名是否稳定
- 治理风险：代币是否有增发权、国库是否由多签控制

### 5.4 市场情绪与共识

- Crypto Fear & Greed：**< 25 极度恐惧 + 价格企稳 = 好的做多窗口；> 75 极度贪婪 = 减仓信号**
- 讨论度：社交热度是否已到极端（极端热度 = 晚期）
- 分析师/机构观点（BTC/ETH）：ETF 流向比言论更有意义

## 六、综合判断与入场时机

### 6.1 评分卡（做多版）

| 维度 | 权重 | 5 分 | 3 分 | 1 分 |
|------|------|------|------|------|
| 叙事与板块动能 | 20% | 板块启动初期、有真实需求数据 | 板块热度中等 | 板块过热或已衰竭 |
| 代币经济学 | 15% | 低通胀 + 无近期解锁 + 有销毁 | 中性 | 高通胀或临近大额解锁 |
| 流动性 | 15% | 24h 成交额 > $100M、深度好 | ≥ $20M | < $5M 或滑点大 |
| 技术面形态 | 20% | 突破回踩 + 多头排列 + 放量 | 均线附近震荡 | 破位或超买追高 |
| 资金面 | 15% | 费率中性 + 交易所净流出 | 费率略高 | 费率极端正 + OI 新高 |
| 催化剂强度 | 15% | 明确未定价的强催化 | 一般催化 | 无催化或已 price in |

**总分 = Σ(维度分 × 权重)**；执行阈值见 00_index（默认 4.0，闸门降级时 4.2）。

### 6.2 入场时机选择

| 场景 | 入场方式 |
|------|---------|
| 突破回踩确认 | 回踩不破 MA20/前高时进 1/3 底仓，站回阻力上方加仓 |
| 超卖反弹（非趋势） | 只做短线，仓位 ≤ 5%，目标前高 |
| 板块启动但标的滞涨 | 等标的自身放量突破，不提前埋伏超过 1/3 仓位 |
| 系统性回调（BTC 跌破 MA50） | **不开新仓**，等闸门恢复 |

## 七、仓位管理与风险控制

### 7.1 仓位规则

- 单标的仓位上限：**10-15%**（默认 12%）；小市值（< $500M）减半至 5-8%
- 同板块合计 ≤ 25%（避免板块同涨同跌）
- 总仓位上限：闸门正常 ≤ 50%；闸门降级 ≤ 35%
- 杠杆：**现货优先**；用永续合约时有效杠杆 ≤ 2 倍（保证金占用按名义额计算）

### 7.2 止损策略

| 方式 | 规则 |
|------|------|
| 结构止损 | 跌破 MA50 或跌破入场依据的关键支撑（前低/整理区下沿） |
| 波动止损 | 入场价 - max(6%, ATR(14) × 2.5)（加密 ATR% 常 3-8%） |
| 时间止损 | 入场后 10 个交易日仍未按预期方向运行 → 减半仓 |
| 系统性止损 | BTC 跌破 200D 或单日全市场爆仓 > $10 亿 → 全部降仓评估 |

### 7.3 目标价设定

- 第一目标：前高 / 上方阻力位（约 10-20% 空间）
- 第二目标：52 周高位区 / 板块市值扩张一致目标
- **分批止盈**：第一目标减 1/3，第二目标减 1/3，剩余跟随（跌破 MA20 全部离场）
- 移动止盈：浮盈 > 20% 后，回撤 8% 触发

## 九、卖出纪律

出现以下任一情况，必须减仓或清仓（不得因"叙事好"而拖延）：

1. **止损触发**（结构/波动/系统性任一）
2. **催化剂兑现**：升级/上线落地后 1-2 日无资金接力（"见光死"确认）
3. **解锁临近**：大额解锁前 3 天（若尚未离场）
4. **费率极端**：资金费率 > 0.1%/8h 持续 2 天
5. **板块资金流出**：该板块 20 日相对 BTC 转为负超额 > 5pct
6. **更好机会**：出现评分显著更高的标的（差额 > 0.5 分）时换仓

```text

    │
    ├─ Step 1  取大盘环境（报告 / price_structure_fallback 降级闸门）

    │
    ├─ Step 3  批量取数（--market crypto --tickers ...）
    │
    ├─ Step 4  项目质量过滤（代币经济学 → 协议基本面 → 排除规则）
    │
    ├─ Step 5  技术面过滤（均线结构 / 形态 / 量能 / 不追高）
    │
    ├─ Step 6  深度尽调与催化剂验证（解锁 / 上币 / 升级 / ETF）
```
